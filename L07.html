01.1Recap: the multiple linear regression model Slides p.1–3

This section writes the model that all of Lecture 7 uses. Page 1 is the title page: "Multiple Linear Regression—Estimation and Inference I". Page 2 is a section page with the title "Recap". Pages 3–5 repeat results from Lecture 6.

What Slides p.3

Recap: Multiple Linear Regression · Lecture 7 · p.3 \[y_i=\beta_0+\beta_1x_{i1}+\cdots+\beta_px_{ip}+\epsilon_i,\qquad \epsilon_i\overset{iid}{\sim}N(0,\sigma^2)\] We can write this: \[\left[\begin{array}{c}y_1\\y_2\\\vdots\\y_n\end{array}\right]=\left[\begin{array}{ccccc}1&x_{11}&x_{12}&\cdots&x_{1p}\\1&x_{21}&x_{22}&\cdots&x_{2p}\\\vdots&\vdots&\vdots&&\vdots\\1&x_{n1}&x_{n2}&\cdots&x_{np}\end{array}\right]\left[\begin{array}{c}\beta_0\\\beta_1\\\vdots\\\beta_p\end{array}\right]+\left[\begin{array}{c}\epsilon_1\\\epsilon_2\\\vdots\\\epsilon_n\end{array}\right]\] Or more simply: \[\boldsymbol{y}=\boldsymbol{X}\boldsymbol\beta+\boldsymbol\epsilon,\quad \boldsymbol\epsilon\sim MVN(\boldsymbol{0},\sigma^2\boldsymbol{I})\iff \boldsymbol{y}\sim MVN(\boldsymbol{X}\boldsymbol\beta,\sigma^2\boldsymbol{I})\]

First, each word and symbol in the statement gets a definition.

Multiple linear regression is a linear model that uses \(p\) explanatory variables to describe one response variable.

The response \(y_i\) is the quantity that we want to explain in observation \(i\). Here \(i=1,\dots,n\), and the sample size \(n\) is the number of observations.

The covariate \(x_{ij}\) is the value of explanatory variable \(j\) in observation \(i\). Here \(j=1,\dots,p\).

The regression coefficients \(\beta_0,\beta_1,\dots,\beta_p\) are unknown constants. \(\beta_0\) is the intercept.

\(\beta_j\) is the change in the mean of \(y_i\) when \(x_{ij}\) increases by 1 and the other covariates do not change.

The error \(\epsilon_i\) is the random part of \(y_i\) that the covariates do not explain.

The symbol \(\overset{iid}{\sim}\) means "independent and identically distributed". The errors do not affect each other, and they all have the same distribution.

The normal distribution \(N(\mu,\sigma^2)\) is a bell-shaped distribution with mean \(\mu\) and variance \(\sigma^2\).

The expectation (or mean) \(E[Z]\) is the theoretical average of a random variable \(Z\). The variance \(\mathrm{Var}(Z)=E[(Z-E[Z])^2]\) measures the spread of \(Z\).

Bold letters are vectors or matrices. The matrix form uses these objects.

\(\boldsymbol{y}\) is the \(n\times1\) response vector. It puts the \(n\) values \(y_i\) in one column.

\(\boldsymbol{X}\) is the \(n\times(p+1)\) design matrix. Column 1 has only 1s, for the intercept. Column \(j+1\) has the \(n\) values of covariate \(j\). Row \(i\) is observation \(i\).

\(\boldsymbol\beta\) is the \((p+1)\times1\) coefficient vector \((\beta_0,\beta_1,\dots,\beta_p)^T\). The superscript \(T\) is the transpose. The transpose changes rows into columns.

\(\boldsymbol\epsilon\) is the \(n\times1\) error vector.

\(MVN(\boldsymbol\mu,\boldsymbol\Sigma)\) is the multivariate normal distribution. \(\boldsymbol\mu\) is the mean vector. \(\boldsymbol\Sigma\) is the variance-covariance matrix. This page calls it the variance matrix.

The diagonal of a variance matrix holds the variance of each element. The other entries hold the covariance of each pair. Covariance measures how two random variables change together.

\(\boldsymbol{I}\) is the \(n\times n\) identity matrix. It has 1s on the diagonal and 0s at all other positions.

\(\sigma^2\boldsymbol{I}\) means that each \(\epsilon_i\) has variance \(\sigma^2\) and that each pair of errors has covariance 0.

The two forms give the same model. The matrix form puts the \(n\) equations into one equation. All derivations in this lecture use the matrix form.

How Added

Write \(\boldsymbol{y}\) and \(\boldsymbol{X}\) from a data table
  1. Find the response column. Put its values in \(\boldsymbol{y}\).
  2. Count the covariates. Call the count \(p\).
  3. Write a column of 1s.
  4. Put the \(p\) covariate columns to the right of the column of 1s. The result is \(\boldsymbol{X}\).

Self-check: \(\boldsymbol{X}\) has \(n\) rows and \(p+1\) columns. \(\boldsymbol{y}\) has \(n\) rows.

Self-check: Column 1 of \(\boldsymbol{X}\) has only 1s.

These four steps change a data table into the matrix form. The next example applies them.

This derivation shows that row \(i\) of the matrix equation gives the scalar equation. Entry \(i\) of \(\boldsymbol{X}\boldsymbol\beta\) is row \(i\) of \(\boldsymbol{X}\) times \(\boldsymbol\beta\), entry by entry, then added.

\[(\boldsymbol{y})_i=(\boldsymbol{X}\boldsymbol\beta)_i+(\boldsymbol\epsilon)_i\]

Row \(i\) of \(\boldsymbol{X}\).

01.2Recap: least squares estimation Slides p.4

This section repeats how to calculate the estimate \(\hat{\boldsymbol\beta}\) from the data. An estimate is a value that we calculate from the data to approximate an unknown parameter. The hat symbol marks an estimate.

What Slides p.4

Least Squares Estimation · Lecture 7 · p.4 Want to minimize the sum of squares, i.e.: \[S(\boldsymbol\beta)=(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)^T(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)=\boldsymbol{y}^T\boldsymbol{y}-\boldsymbol{y}^T\boldsymbol{X}\boldsymbol\beta-\boldsymbol\beta^T\boldsymbol{X}^T\boldsymbol{y}+\boldsymbol\beta^T\boldsymbol{X}^T\boldsymbol{X}\boldsymbol\beta=\boldsymbol{y}^T\boldsymbol{y}-2\boldsymbol{y}^T\boldsymbol{X}\boldsymbol\beta+\boldsymbol\beta^T\boldsymbol{X}^T\boldsymbol{X}\boldsymbol\beta\] \[\frac{\partial S(\boldsymbol\beta)}{\partial\boldsymbol\beta}=-2\boldsymbol{X}^T\boldsymbol{y}+2\boldsymbol{X}^T\boldsymbol{X}\boldsymbol\beta=0\ \Rightarrow\ (\boldsymbol{X}^T\boldsymbol{X})\boldsymbol\beta=\boldsymbol{X}^T\boldsymbol{y}\ \Rightarrow\ \hat{\boldsymbol\beta}=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{y}\] assuming the columns of \(\boldsymbol{X}\) are linearly independent

Each part of the statement gets a definition.

Least squares is the method that selects \(\boldsymbol\beta\) to make the sum of squared differences between \(\boldsymbol{y}\) and \(\boldsymbol{X}\boldsymbol\beta\) as small as possible.

\(S(\boldsymbol\beta)\) is the sum of squares. In scalar form, \(S(\boldsymbol\beta)=\sum_{i=1}^n(y_i-\beta_0-\beta_1x_{i1}-\cdots-\beta_px_{ip})^2\).

\(\partial S/\partial\boldsymbol\beta\) is the gradient. It is the column of the partial derivatives of \(S\) with respect to \(\beta_0,\dots,\beta_p\).

At the minimum, the gradient is the zero vector. This gives the normal equations \((\boldsymbol{X}^T\boldsymbol{X})\boldsymbol\beta=\boldsymbol{X}^T\boldsymbol{y}\): \(p+1\) equations in \(p+1\) unknowns.

\((\boldsymbol{X}^T\boldsymbol{X})^{-1}\) is the inverse of \(\boldsymbol{X}^T\boldsymbol{X}\). It satisfies \((\boldsymbol{X}^T\boldsymbol{X})^{-1}(\boldsymbol{X}^T\boldsymbol{X})=\boldsymbol{I}\).

The columns of \(\boldsymbol{X}\) are linearly independent when no column is a linear combination of the other columns. This condition makes \(\boldsymbol{X}^T\boldsymbol{X}\) invertible.

How Added

Calculate \(\hat{\boldsymbol\beta}\)
  1. Calculate \(\boldsymbol{X}^T\boldsymbol{X}\). Entry \((j,k)\) is column \(j\) of \(\boldsymbol{X}\) times column \(k\), entry by entry, then added.
  2. Calculate \(\boldsymbol{X}^T\boldsymbol{y}\). Entry \(j\) is column \(j\) of \(\boldsymbol{X}\) times \(\boldsymbol{y}\), entry by entry, then added.
  3. Calculate the inverse \((\boldsymbol{X}^T\boldsymbol{X})^{-1}\).
  4. Multiply: \(\hat{\boldsymbol\beta}=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{y}\).

Self-check: \(\boldsymbol{X}^T\boldsymbol{X}\) is \((p+1)\times(p+1)\) and symmetric. Symmetric means that the transpose is the same matrix. The top-left entry is \(n\).

Self-check: \(\hat{\boldsymbol\beta}\) satisfies the normal equations \((\boldsymbol{X}^T\boldsymbol{X})\hat{\boldsymbol\beta}=\boldsymbol{X}^T\boldsymbol{y}\).

These four steps give \(\hat{\boldsymbol\beta}\) from \(\boldsymbol{X}\) and \(\boldsymbol{y}\). The next example applies them to data set 1.

\[S(\boldsymbol\beta)=(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)^T(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)\]

Rule A.

01.3Recap: properties of \(\hat{\boldsymbol\beta}\) Slides p.5

This section repeats the sampling distribution of \(\hat{\boldsymbol\beta}\). The sampling distribution is the distribution of \(\hat{\boldsymbol\beta}\) over many new data sets with the same \(\boldsymbol{X}\). Tests and confidence intervals later in this lecture use it.

What Slides p.5

Properties of \(\hat{\boldsymbol\beta}\) · Lecture 7 · p.5 \[\hat{\boldsymbol\beta}\sim N(\boldsymbol\beta,\ \sigma^2(\boldsymbol{X}^T\boldsymbol{X})^{-1})\ \Longrightarrow\ \hat\beta_j\sim N(\beta_j,\sigma^2V_{jj})\] where \(V_{jj}\) is the corresponding diagonal of \(\boldsymbol{V}=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\).
Note: the notation here is a little funky due to 0-indexing \(\boldsymbol\beta\): \[\mathrm{Var}(\hat{\boldsymbol\beta})=\mathrm{Var}\left(\left[\begin{array}{c}\hat\beta_0\\\hat\beta_1\\\vdots\\\hat\beta_p\end{array}\right]\right)=\sigma^2\left[\begin{array}{cccc}V_{00}&V_{01}&\cdots&V_{0p}\\V_{10}&V_{11}&\cdots&V_{1p}\\\vdots&&&\vdots\\V_{p0}&V_{p1}&\cdots&V_{pp}\end{array}\right]\]

The statement has four parts.

The mean of \(\hat{\boldsymbol\beta}\) is the true \(\boldsymbol\beta\). Thus \(\hat{\boldsymbol\beta}\) is unbiased. An unbiased estimator has a mean equal to the parameter that it estimates.

The variance matrix of \(\hat{\boldsymbol\beta}\) is \(\sigma^2\boldsymbol{V}\), with \(\boldsymbol{V}=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\).

The variance of one coefficient \(\hat\beta_j\) is \(\sigma^2V_{jj}\). \(V_{jj}\) is a diagonal entry of \(\boldsymbol{V}\).

0-indexing means that the numbers of the rows and columns of \(\boldsymbol{V}\) start at 0, as for \(\beta_0\). \(V_{00}\) is in row 1, column 1. \(V_{jj}\) is in row \(j+1\), column \(j+1\).

How Added

Find \(\mathrm{Var}(\hat\beta_j)\)
  1. Calculate \(\boldsymbol{V}=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\).
  2. Find the diagonal entry for \(\hat\beta_j\). It is in row \(j+1\), column \(j+1\).
  3. Write \(\mathrm{Var}(\hat\beta_j)=\sigma^2V_{jj}\) and \(\hat\beta_j\sim N(\beta_j,\sigma^2V_{jj})\).

Self-check: \(V_{jj}>0\). A variance divided by \(\sigma^2\) cannot be negative.

Self-check: The row number is the index \(j\) plus 1.

These three steps give the variance of each coefficient, up to the unknown factor \(\sigma^2\). The next example applies them.

Why · The distribution of \(\hat{\boldsymbol\beta}\) Added

This derivation repeats the result from Lecture 6. It uses one property of the multivariate normal distribution. If \(\boldsymbol{y}\sim MVN(\boldsymbol\mu,\boldsymbol\Sigma)\) and \(\boldsymbol{A}\) is a constant matrix, then \(\boldsymbol{A}\boldsymbol{y}\sim MVN(\boldsymbol{A}\boldsymbol\mu,\boldsymbol{A}\boldsymbol\Sigma\boldsymbol{A}^T)\). Let \(\boldsymbol{A}=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\). Then \(\hat{\boldsymbol\beta}=\boldsymbol{A}\boldsymbol{y}\).

1

Mean

\[E[\hat{\boldsymbol\beta}]=\boldsymbol{A}\boldsymbol{X}\boldsymbol\beta=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{X}\boldsymbol\beta\]

Substitute \(\boldsymbol\mu=\boldsymbol{X}\boldsymbol\beta\) (Section 01.1).

2
\[E[\hat{\boldsymbol\beta}]=\boldsymbol{I}\boldsymbol\beta=\boldsymbol\beta\]
3

Variance

\[\mathrm{Var}(\hat{\boldsymbol\beta})=\boldsymbol{A}(\sigma^2\boldsymbol{I})\boldsymbol{A}^T=\sigma^2(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{X}\left[(\boldsymbol{X}^T\boldsymbol{X})^{-1}\right]^T\]

Substitute \(\boldsymbol\Sigma=\sigma^2\boldsymbol{I}\). Rule A gives \(\boldsymbol{A}^T=\boldsymbol{X}\left[(\boldsymbol{X}^T\boldsymbol{X})^{-1}\right]^T\).

4
\[\mathrm{Var}(\hat{\boldsymbol\beta})=\sigma^2\boldsymbol{I}\left[(\boldsymbol{X}^T\boldsymbol{X})^{-1}\right]^T\]
5
\[\mathrm{Var}(\hat{\boldsymbol\beta})=\sigma^2(\boldsymbol{X}^T\boldsymbol{X})^{-1}\]

\(\boldsymbol{X}^T\boldsymbol{X}\) is symmetric, thus its inverse is symmetric. Entry \(j\) gives \(\hat\beta_j\sim N(\beta_j,\sigma^2V_{jj})\). ∎

01.4Fitted values and the hat matrix Slides p.6–7

Page 6 repeats the title page. It shows that the new material starts here. This section defines the fitted values and writes them as one matrix times \(\boldsymbol{y}\).

What Slides p.7

The fitted value \(\hat y_i\) is the value that the estimated model gives for observation \(i\): \(\hat y_i=\hat\beta_0+\hat\beta_1x_{i1}+\cdots+\hat\beta_px_{ip}\). The vector \(\hat{\boldsymbol{y}}\) puts the \(n\) fitted values in one column.

Fitted values · Lecture 7 · p.7 \[\hat{\boldsymbol{y}}=\boldsymbol{X}\hat{\boldsymbol\beta}=\boldsymbol{X}\left[(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{y}\right]=\left[\boldsymbol{X}(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\right]\boldsymbol{y}=\boldsymbol{H}\boldsymbol{y}\] where \(\boldsymbol{H}=\boldsymbol{X}(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\) is called the Hat matrix.

The hat matrix \(\boldsymbol{H}\) is an \(n\times n\) matrix. When it multiplies \(\boldsymbol{y}\), the result is \(\hat{\boldsymbol{y}}\). It "puts the hat on" \(\boldsymbol{y}\).

\(\boldsymbol{H}\) depends only on \(\boldsymbol{X}\). It does not contain \(\boldsymbol{y}\).

Thus each \(\hat y_i\) is a linear combination of \(y_1,\dots,y_n\). The weights are the entries of row \(i\) of \(\boldsymbol{H}\).

01.5Residuals and \(\boldsymbol{X}^T\boldsymbol{e}=\boldsymbol{0}\) Slides p.8–9

This section defines the residuals. Then it shows that the residual vector is orthogonal to each column of \(\boldsymbol{X}\). Unit 02 uses this property to estimate \(\sigma^2\).

What Slides p.8–9

The residual \(e_i\) is the observed value minus the fitted value: \(e_i=y_i-\hat y_i\). It is the part of \(y_i\) that the estimated model does not fit. The vector \(\boldsymbol{e}\) puts the \(n\) residuals in one column.

Residuals · Lecture 7 · p.8–9 \[\boldsymbol{e}=\boldsymbol{y}-\hat{\boldsymbol{y}}=\boldsymbol{y}-\boldsymbol{X}\hat{\boldsymbol\beta}=\boldsymbol{y}-\boldsymbol{H}\boldsymbol{y}=(\boldsymbol{I}-\boldsymbol{H})\boldsymbol{y}.\] Note: \(\boldsymbol{X}^T\boldsymbol{e}=\boldsymbol{0}\). Why? \[\boldsymbol{X}^T\boldsymbol{e}=\boldsymbol{X}^T(\boldsymbol{y}-\boldsymbol{H}\boldsymbol{y})=\boldsymbol{X}^T\boldsymbol{y}-\boldsymbol{X}^T\boldsymbol{X}(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{y}=\boldsymbol{X}^T\boldsymbol{y}-\boldsymbol{X}^T\boldsymbol{y}=\boldsymbol{0}\]

The residual \(e_i\) is not the error \(\epsilon_i\). The error \(\epsilon_i=y_i-\boldsymbol{x}_i^T\boldsymbol\beta\) uses the true \(\boldsymbol\beta\), so we cannot see it.

The residual \(e_i=y_i-\boldsymbol{x}_i^T\hat{\boldsymbol\beta}\) uses the estimate \(\hat{\boldsymbol\beta}\), so we can calculate it. Here \(\boldsymbol{x}_i^T\) is row \(i\) of \(\boldsymbol{X}\).

\(\boldsymbol{e}=(\boldsymbol{I}-\boldsymbol{H})\boldsymbol{y}\) shows that \(\boldsymbol{e}\) is also a matrix that depends only on \(\boldsymbol{X}\), times \(\boldsymbol{y}\).

\(\boldsymbol{X}^T\boldsymbol{e}=\boldsymbol{0}\) is \(p+1\) equations. The inner product of each column of \(\boldsymbol{X}\) with \(\boldsymbol{e}\) is 0.

The inner product of two vectors is the sum of the products of their entries. Two vectors are orthogonal when their inner product is 0.

Column 1 of \(\boldsymbol{X}\) has only 1s. Thus the first equation is \(\sum_{i=1}^ne_i=0\): the residuals add to 0.

02.1The MLE of \(\sigma^2\) Slides p.10–12

This section finds the first estimator of \(\sigma^2\) with the maximum likelihood method. Slide p.10 is the section page "Estimating \(\sigma^2\)".

Lecture 6 gives the estimate \(\hat{\boldsymbol\beta}\). The parameter \(\sigma^2\) is still unknown. The variance of \(\hat{\boldsymbol\beta}\) contains \(\sigma^2\). Thus, you must estimate \(\sigma^2\) before you can calculate standard errors and confidence intervals.

What Slides p.11–12

Three terms are necessary for this section.

Likelihood: the joint density of the observed \(\boldsymbol y\), as a function of the parameters \((\boldsymbol\beta,\sigma^2)\). A larger value means that the parameters agree better with the data.
Log-likelihood \(\ell(\boldsymbol\beta,\sigma^2|\boldsymbol y)\): the natural logarithm of the likelihood. The logarithm is an increasing function. Thus, both functions have their maximum at the same point.
Maximum likelihood estimate (MLE): the parameter value that makes the log-likelihood as large as possible.
Lecture 7 · p.11–12 \[\ell(\boldsymbol\beta,\sigma^2|\boldsymbol y)=-\frac{n}{2}\log(2\pi)-\frac{n}{2}\log\sigma^2-\frac{1}{2\sigma^2}(\boldsymbol y-\boldsymbol X\boldsymbol\beta)^T(\boldsymbol y-\boldsymbol X\boldsymbol\beta)\] \[\frac{\partial\ell(\boldsymbol\beta,\sigma^2|\boldsymbol y)}{\partial\sigma^2}=-\frac{n}{2\sigma^2}+\frac{1}{2(\sigma^2)^2}(\boldsymbol y-\boldsymbol X\boldsymbol\beta)^T(\boldsymbol y-\boldsymbol X\boldsymbol\beta)=0\] \[(\boldsymbol y-\boldsymbol X\boldsymbol\beta)^T(\boldsymbol y-\boldsymbol X\boldsymbol\beta)=n\sigma^2\] \[\Longrightarrow\ \hat\sigma^2_{MLE}=\frac{1}{n}(\boldsymbol y-\boldsymbol X\hat{\boldsymbol\beta})^T(\boldsymbol y-\boldsymbol X\hat{\boldsymbol\beta})\]

The first line is the log of the density of \(\boldsymbol y\sim MVN(\boldsymbol X\boldsymbol\beta,\sigma^2\boldsymbol I)\). The second line sets the partial derivative with respect to \(\sigma^2\) equal to 0. A partial derivative is the rate of change when only one variable changes. The last two lines solve for \(\sigma^2\). The MLE of \(\boldsymbol\beta\) is the least squares estimate \(\hat{\boldsymbol\beta}\), so the last line uses \(\hat{\boldsymbol\beta}\).

The product \((\boldsymbol y-\boldsymbol X\hat{\boldsymbol\beta})^T(\boldsymbol y-\boldsymbol X\hat{\boldsymbol\beta})\) is \(\boldsymbol e^T\boldsymbol e=\sum_{i=1}^n e_i^2\). This sum is the sum of squared residuals. Thus, \(\hat\sigma^2_{MLE}=\frac{1}{n}\boldsymbol e^T\boldsymbol e\), the mean of the squared residuals.

How Added

Use these steps to calculate \(\hat\sigma^2_{MLE}\).

Calculate \(\hat\sigma^2_{MLE}\)
  1. Calculate \(\hat{\boldsymbol\beta}\) and the residuals \(\boldsymbol e=\boldsymbol y-\boldsymbol X\hat{\boldsymbol\beta}\).
  2. Square each residual.
  3. Add the squares to get \(\boldsymbol e^T\boldsymbol e\).
  4. Divide \(\boldsymbol e^T\boldsymbol e\) by the number of observations \(n\).

02.2The unbiased estimate of \(\sigma^2\) Slides p.13

This section gives the estimator of \(\sigma^2\) that the course uses for inference.

What Slides p.13

Two terms are necessary for this section.

Estimator: a quantity that you calculate from the data to estimate a parameter. It changes with the data, so it is a random variable.
Unbiased: the expected value of the estimator is equal to the true parameter. For example, \(E[\hat\sigma^2]=\sigma^2\).
Lecture 7 · p.13

The MLE of \(\sigma^2\) is \(\frac{1}{n}\boldsymbol e^T\boldsymbol e\), where \(\boldsymbol e=\boldsymbol y-\boldsymbol X\hat{\boldsymbol\beta}\).

Instead we usually use \(\hat\sigma^2=\frac{1}{n-(p+1)}\boldsymbol e^T\boldsymbol e\). Why?

The two estimators have the same numerator \(\boldsymbol e^T\boldsymbol e\). Only the denominator is different. The MLE divides by \(n\). The estimator \(\hat\sigma^2\) divides by \(n-(p+1)\).

The number \(p+1\) is the number of entries in \(\boldsymbol\beta\): one intercept and \(p\) slopes. The number \(n-(p+1)\) is the residual degrees of freedom. It is the number of observations minus the number of estimated coefficients. The slide title says "Unbiased": \(\hat\sigma^2\) is an unbiased estimator of \(\sigma^2\).

Slide p.13 only asks "Why?". Unit 04 gives the answer: it shows \(\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\sim\chi^2_{n-(p+1)}\). The results of slides p.14–25 prepare that proof.

How Added

  4. Divide \(\boldsymbol e^T\boldsymbol e\) by \(n-(p+1)\) to get \(\hat\sigma^2\).

Self-check: \(\hat\sigma^2\) must be larger than \(\hat\sigma^2_{MLE}\). The ratio \(\hat\sigma^2/\hat\sigma^2_{MLE}\) must be equal to \(n/(n-(p+1))\).

02.3Stack \(\hat{\boldsymbol\beta}\) and \(\boldsymbol e\) into one vector Slides p.14

This section writes \(\hat{\boldsymbol\beta}\) and \(\boldsymbol e\) together as one constant matrix times \(\boldsymbol y\). Then one property of the MVN gives their joint distribution. A joint distribution is the distribution of several random quantities together.

What Slides p.14

Lecture 7 · p.14

Recall \(\hat{\boldsymbol\beta}=(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\boldsymbol y\) and \(\boldsymbol e=(\boldsymbol I-\boldsymbol H)\boldsymbol y\).

Let's consider the vector \(\left[\begin{array}{c}\hat{\boldsymbol\beta}\\ \boldsymbol e\end{array}\right]\), which is a linear combination of \(\boldsymbol y\):

\[\left[\begin{array}{c}\hat{\boldsymbol\beta}\\ \boldsymbol e\end{array}\right]=\left[\begin{array}{c}(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\\ \boldsymbol I-\boldsymbol H\end{array}\right]\boldsymbol y\]

And since \(\boldsymbol y\sim N(\boldsymbol X\boldsymbol\beta,\sigma^2\boldsymbol I)\), then \(\left[\begin{array}{c}\hat{\boldsymbol\beta}\\ \boldsymbol e\end{array}\right]\) is MVN-distributed.

The top part of the stacked vector is \(\hat{\boldsymbol\beta}\), with \(p+1\) entries. The bottom part is \(\boldsymbol e\), with \(n\) entries. Thus, the stacked vector is \((p+1+n)\times1\). The matrix on the right is \((p+1+n)\times n\). A linear combination of \(\boldsymbol y\) is a sum of the entries \(y_1,\dots,y_n\), each multiplied by a constant.

02.4The mean of the stacked vector Slides p.15–16

What Slides p.15–16

02.5The variance matrix of the stacked vector Slides p.17–18

This section finds the variance matrix of the stacked vector. The result is a matrix with four blocks.

A covariance measures how two random quantities change together. Entry \((i,j)\) of a variance matrix is the covariance of component \(i\) and component \(j\). The diagonal entries are the variances of the components.

What Slides p.17–18

Lecture 7 · p.18 \[\begin{array}{rl}\mathrm{Var}\left(\left[\begin{array}{c}\hat{\boldsymbol\beta}\\ \boldsymbol e\end{array}\right]\right)&=\mathrm{Var}\left(\left[\begin{array}{c}(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\\ (\boldsymbol I-\boldsymbol H)\end{array}\right]\boldsymbol y\right)\\ &=\left[\begin{array}{c}(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\\ (\boldsymbol I-\boldsymbol H)\end{array}\right]\mathrm{Var}(\boldsymbol y)\left[\begin{array}{c}(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\\ (\boldsymbol I-\boldsymbol H)\end{array}\right]^T\\ &=\left[\begin{array}{c}(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\\ (\boldsymbol I-\boldsymbol H)\end{array}\right](\sigma^2\boldsymbol I)\left[((\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T)^T,\ (\boldsymbol I-\boldsymbol H)^T\right]\\ &=\sigma^2\left[\begin{array}{c}(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\\ (\boldsymbol I-\boldsymbol H)\end{array}\right]\left[\boldsymbol X(\boldsymbol X^T\boldsymbol X)^{-1},\ (\boldsymbol I-\boldsymbol H)\right]\\ &=\sigma^2\left[\begin{array}{cc}(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\boldsymbol X(\boldsymbol X^T\boldsymbol X)^{-1} & (\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T(\boldsymbol I-\boldsymbol H)\\ (\boldsymbol I-\boldsymbol H)\boldsymbol X(\boldsymbol X^T\boldsymbol X)^{-1} & (\boldsymbol I-\boldsymbol H)(\boldsymbol I-\boldsymbol H)\end{array}\right]\\ &=\sigma^2\left[\begin{array}{cc}\boldsymbol A & \boldsymbol B\\ \boldsymbol C & \boldsymbol D\end{array}\right]\end{array}\]

03.1Symbols and distributions Added

This section defines the distributions and symbols of this unit. Units 01–02 define the MLR model, \(\hat{\boldsymbol\beta}\), \(\boldsymbol H\), \(\boldsymbol e\), \(\boldsymbol V\), and \(\hat\sigma^2\) (Sections 01.1–01.5 and 02.2).

Random variable: a number whose value comes from a random experiment. A new data set gives a new value. \(\hat\beta_1\), \(\hat\sigma^2\), and \(e_i\) are random variables.
Standard normal distribution \(N(0,1)\): the normal distribution with mean 0 and variance 1. If \(W\sim N(\mu,\sigma^2)\), then the standardized value \((W-\mu)/\sigma\sim N(0,1)\).
Chi-squared distribution \(\chi^2_\nu\): the distribution of a sum of \(\nu\) squared independent \(N(0,1)\) random variables. The number \(\nu\) is the degrees of freedom (Slides p.29 uses this definition).
Independent: two random variables are independent when the value of one gives no information about the value of the other.
t distribution \(t_\nu\): a distribution with a bell shape, symmetric about 0, like \(N(0,1)\). Its tails are thicker. Slides p.26 gives its definition as \(Z/\sqrt{V/\nu}\).
SLR model: \(y_i=\beta_0+\beta_1x_i+\epsilon_i\), with \(\epsilon_i\overset{iid}{\sim}N(0,\sigma^2)\). \(S_{xx}=\sum_{i=1}^n(x_i-\bar x)^2\). The residual is \(e_i=y_i-\hat y_i\), the observed value minus the fitted value.
The slides use the letter V in two ways. A plain \(V\) with no index is the chi-squared quantity \(\frac{1}{\sigma^2}\sum e_i^2\) of Slides p.26. A bold \(\boldsymbol V\) is the matrix \((\boldsymbol X^T\boldsymbol X)^{-1}\).
Standard error (SE): the standard deviation of an estimator, with \(\hat\sigma\) in place of \(\sigma\). In SLR, \(\mathrm{SE}(\hat\beta_1)=\hat\sigma/\sqrt{S_{xx}}\). In MLR, \(\mathrm{SE}(\hat\beta_j)=\sqrt{\hat\sigma^2V_{jj}}\).

All symbols are now defined. Section 03.2 recalls how SLR gets its t statistic, because MLR uses the same plan.

03.2Recall: the t statistic in SLR Slides p.26

This section states again the result of Lecture 3. Three facts and one combination rule give \(\dfrac{\hat\beta_1-\beta_1}{\hat\sigma/\sqrt{S_{xx}}}\sim t_{n-2}\).

What Slides p.26

Recall: OLS in Simple Linear Regression · Lecture 7 · p.26 \[\frac{\hat\beta_1-\beta_1}{\sigma/\sqrt{S_{xx}}}\sim N(0,1)\] But \(\sigma\) is unknown in practice, so we actually need the distribution when we replace \(\sigma\) by \(\hat\sigma\).
And we used the following: (we showed 1 but only claimed 2 & 3)
1. \(Z=\dfrac{\hat\beta_1-\beta_1}{\sigma/\sqrt{S_{xx}}}\sim N(0,1)\)
2. \(V=\dfrac{1}{\sigma^2}\sum_{i=1}^ne_i^2\sim\chi^2_{(n-2)}\)
3. \(Z\) and \(V\) are independent
Then if (1) \(Z\sim N(0,1)\), (2) \(V\sim\chi^2_\nu\) and (3) \(V\) independent of \(Z\): \(\Longrightarrow\dfrac{Z}{\sqrt{V/\nu}}\sim t_\nu\) \[\Longrightarrow\frac{Z}{\sqrt{V/\nu}}=\frac{\dfrac{\hat\beta_1-\beta_1}{\sigma/\sqrt{S_{xx}}}}{\sqrt{\dfrac{1}{\sigma^2}\sum_{i=1}^ne_i^2/(n-2)}}\sim t_{n-2}\] \[\frac{\hat\beta_1-\beta_1}{\hat\sigma/\sqrt{S_{xx}}}\sim t_{n-2}\]

The statement has three parts. First, when \(\sigma\) is known, the standardized \(\hat\beta_1\) has the \(N(0,1)\) distribution. Second, in practice \(\sigma\) is unknown, so we use \(\hat\sigma\) in its place. Then the denominator is also random, and the distribution is not \(N(0,1)\). Third, when the three facts are true, the combination rule gives the new distribution \(t_{n-2}\).

\(Z\) uses only \(\hat\beta_1\). It contains the true \(\sigma\), so we cannot calculate it from data. We use it only in the proof.
\(V\) uses only the residuals \(e_i\). Its degrees of freedom are \(n-2\), because SLR estimates 2 coefficients, \(\beta_0\) and \(\beta_1\).
Combination rule (the definition of the t distribution): divide a chi-squared by its degrees of freedom, and take the square root. Divide an independent standard normal by this value. The result has the t distribution with the same degrees of freedom.

The note in brackets on the slide says that Lecture 3 proved fact 1 only. Facts 2 and 3 were only claimed. This lecture proves them for MLR. SLR is the special case \(p=1\).

How Added

Get a t statistic from the three facts and the combination rule
  1. Write \(Z\). Subtract the parameter from the estimator. Divide by the standard deviation that uses the true \(\sigma\). Make sure that \(Z\sim N(0,1)\).
  2. Write \(V\). Divide the residual sum of squares by \(\sigma^2\). Make sure that \(V\sim\chi^2_\nu\). Record \(\nu\).
  3. Make sure that \(Z\) and \(V\) are independent.
  4. Put \(Z\) and \(V\) into \(Z/\sqrt{V/\nu}\). Cancel \(\sigma\). Write \(\sum e_i^2/\nu\) as \(\hat\sigma^2\). The result has the \(t_\nu\) distribution.

What Slides p.28

\(\hat\sigma^2\): (3) Independence · Lecture 7 · p.28 Recall: \[\left[\begin{array}{c}\hat{\boldsymbol\beta}\\\boldsymbol e\end{array}\right]\sim N\left(\left[\begin{array}{c}\boldsymbol\beta\\\boldsymbol 0\end{array}\right],\ \sigma^2\left[\begin{array}{cc}(\boldsymbol X^T\boldsymbol X)^{-1}&\boldsymbol 0\\\boldsymbol 0&(\boldsymbol I-\boldsymbol H)\end{array}\right]\right)\] \[\Longrightarrow \boldsymbol e\text{ is independent of }\hat{\boldsymbol\beta}\] \[\Longrightarrow\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\text{ is independent of }\hat{\boldsymbol\beta}\]

Its variance matrix has four blocks. Covariance is a measure of how two random variables change together; 0 means no linear relation.

Top-left block \(\sigma^2(\boldsymbol X^T\boldsymbol X)^{-1}\): the variance matrix of \(\hat{\boldsymbol\beta}\), \(\mathrm{Var}(\hat{\boldsymbol\beta})\).
Bottom-right block \(\sigma^2(\boldsymbol I-\boldsymbol H)\): the variance matrix of \(\boldsymbol e\), \(\mathrm{Var}(\boldsymbol e)\).
Top-right and bottom-left blocks \(\boldsymbol 0\): the covariances \(\mathrm{Cov}(\hat{\boldsymbol\beta},\boldsymbol e)\) between each element of \(\hat{\boldsymbol\beta}\) and each element of \(\boldsymbol e\). All of them are 0.

Recall for \(Z_i\overset{iid}{\sim}N(0,1)\): \[\sum_{i=1}^{\nu}Z_i^2\sim\chi^2_\nu\] So we want to write \(\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\) as a sum of squared independent standard normal r.v.s. We could write: \(\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e=\sum_{i=1}^n\left(\frac{e_i}{\sigma}\right)^2\) ... Problem: the \(e_i\) are not independent! (why?) Solution: let's rewrite \(\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\) as a sum of squared independent normal r.v.s

The next lines define the terms in the statement.

Chi-squared distribution \(\chi^2_\nu\): the distribution of the sum of squares of \(\nu\) independent standard normal random variables.
Degrees of freedom \(\nu\): the number of independent standard normal terms in that sum.
r.v.: random variable. "iid" means independent and identically distributed: the variables are independent and have the same distribution.
Standard normal: the normal distribution \(N(0,1)\), with mean 0 and variance 1.

In words: the chi-squared definition has two conditions. Each term must be normal with variance 1. The terms must be independent. Each \(e_i/\sigma\) is normal, but the terms are not independent. Thus, the proof must find new variables that are independent and that give the same sum of squares.

How Added

  1. Write the sum in the form \(\sum_i Z_i^2\). Identify each \(Z_i\).

  4. Count the terms. This count is the degrees of freedom \(\nu\).

04.2Eigen decomposition and the distribution of \(\tilde{\boldsymbol e}=\boldsymbol\Gamma\boldsymbol e\) Slides p.31–36

This section multiplies \(\boldsymbol e\) by an orthogonal matrix \(\boldsymbol\Gamma\) to get \(\tilde{\boldsymbol e}\). It then shows that the entries of \(\tilde{\boldsymbol e}\) are independent.

What Slides p.31–36

Lecture 7 · p.31–36 We have \(\boldsymbol e=(\boldsymbol I-\boldsymbol H)\boldsymbol y\), and we consider the eigen decomposition \(\boldsymbol I-\boldsymbol H=\boldsymbol\Gamma^T\boldsymbol D\boldsymbol\Gamma\) where \[\boldsymbol\Gamma^{-1}=\boldsymbol\Gamma^T\quad\text{and}\quad\boldsymbol D=\left[\begin{array}{ccc}\lambda_1&&\\&\ddots&\\&&\lambda_n\end{array}\right]\] Define \(\tilde{\boldsymbol e}=\boldsymbol\Gamma\boldsymbol e\). Now, what is the distribution of \(\tilde{\boldsymbol e}\)? \[E[\tilde{\boldsymbol e}]=E[\boldsymbol\Gamma\boldsymbol e]=\boldsymbol\Gamma E[\boldsymbol e]=\boldsymbol 0\] \[\mathrm{Var}[\tilde{\boldsymbol e}]=\mathrm{Var}[\boldsymbol\Gamma\boldsymbol e]=\boldsymbol\Gamma \mathrm{Var}[\boldsymbol e]\boldsymbol\Gamma^T=\sigma^2\boldsymbol\Gamma(\boldsymbol I-\boldsymbol H)\boldsymbol\Gamma^T=\sigma^2\boldsymbol\Gamma(\boldsymbol\Gamma^T\boldsymbol D\boldsymbol\Gamma)\boldsymbol\Gamma^T=\sigma^2\boldsymbol D\] and \(\tilde{\boldsymbol e}\sim N(\boldsymbol 0,\sigma^2\boldsymbol D)\) (why?) \[\Longrightarrow\ \tilde e_i\overset{indep}{\sim}N(0,\sigma^2\lambda_i)\]

The next lines define the terms in the statement.

Eigenvalue and eigenvector: a nonzero vector \(\boldsymbol v_i\) with \(\boldsymbol A\boldsymbol v_i=\lambda_i\boldsymbol v_i\) is an eigenvector of \(\boldsymbol A\). The number \(\lambda_i\) is its eigenvalue.
Diagonal matrix: a square matrix whose off-diagonal entries are all 0. \(\boldsymbol D\) is diagonal, with the eigenvalues \(\lambda_1,\dots,\lambda_n\) on the diagonal.
Orthogonal matrix: a square matrix with \(\boldsymbol\Gamma^{-1}=\boldsymbol\Gamma^T\). Thus \(\boldsymbol\Gamma\boldsymbol\Gamma^T=\boldsymbol\Gamma^T\boldsymbol\Gamma=\boldsymbol I\). Multiplication by \(\boldsymbol\Gamma\) does not change the length of a vector.
Eigen decomposition: the form \(\boldsymbol\Gamma^T\boldsymbol D\boldsymbol\Gamma\) of a symmetric matrix. Row \(i\) of \(\boldsymbol\Gamma\) is an eigenvector of length 1 for \(\lambda_i\).
indep: independent. \(\tilde e_i\overset{indep}{\sim}N(0,\sigma^2\lambda_i)\) means that the \(\tilde e_i\) are independent, and entry \(i\) has variance \(\sigma^2\lambda_i\).

In words: the variance matrix \(\sigma^2(\boldsymbol I-\boldsymbol H)\) of \(\boldsymbol e\) is not diagonal. Thus, the entries of \(\boldsymbol e\) are correlated. The variance matrix of \(\tilde{\boldsymbol e}=\boldsymbol\Gamma\boldsymbol e\) is \(\sigma^2\boldsymbol D\), which is diagonal. For a multivariate normal vector, zero covariance gives independence. Thus, \(\tilde e_1,\dots,\tilde e_n\) are independent.

04.4Each \(\lambda_i\) is 0 or 1 Slides p.39–40

This section works on the condition "variance 1". It shows that each eigenvalue of \(\boldsymbol I-\boldsymbol H\) is 0 or 1.

What Slides p.39–40

Lecture 7 · p.39–40 So \(\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\) is a sum of squared independent normally distributed r.v.'s.
• Recall: need a sum of independent standard normally distributed r.v.'s (var=1)
• And: we need to sum up exactly \(n-(p+1)\) of these r.v.s
So: to show \(\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\sim\chi^2_{(n-(p+1))}\), we will show that \(n-(p+1)\) of the \(\lambda_i\)'s are equal to 1, and the remainder are all 0.
Let's first show that all of the \(\lambda_i\)'s are equal to either 0 or 1:
• We know that \((\boldsymbol I-\boldsymbol H)(\boldsymbol I-\boldsymbol H)=(\boldsymbol I-\boldsymbol H)\); i.e. \((\boldsymbol I-\boldsymbol H)\) is idempotent.
• The eigenvalues (elements \(\lambda_i\) of \(\boldsymbol D\)) of an idempotent matrix are equal to 0 or 1.
• Why? By definition of eigenvalue \(\lambda_i\) and corresponding eigenvector \(\boldsymbol v_i\), we know: \(\lambda_i\boldsymbol v_i=(\boldsymbol I-\boldsymbol H)\boldsymbol v_i\)
Thus all \(\lambda_i\) are either 0 or 1.

The next lines define the terms in the statement.

Idempotent matrix: a square matrix \(\boldsymbol A\) with \(\boldsymbol A\boldsymbol A=\boldsymbol A\).
Degenerate random variable: a random variable with variance 0. It always has the same value. A variable with distribution \(N(0,0)\) is always 0.

In words: if \(\lambda_i=1\), then \(Z_i\sim N(0,1)\). This is a standard normal variable. If \(\lambda_i=0\), then \(Z_i\sim N(0,0)\), so \(Z_i=0\) and \(Z_i^2\) adds 0 to the sum. Thus, when each \(\lambda_i\) is 0 or 1, the sum contains only standard normal squares and zeros.

  3. If all entries are equal, write that \(\boldsymbol A\) is idempotent. Then each eigenvalue is 0 or 1.

04.5\(\sum_i\lambda_i=n-(p+1)\): count the 1s with the trace Slides p.41–42

This section works on the condition "exactly \(n-(p+1)\) terms". Each \(\lambda_i\) is 0 or 1, so their sum is the count of 1s.

What Slides p.41–42

Lecture 7 · p.41–42 Now, if all the \(\lambda_i\) are 0 or 1, then we can show that exactly \(n-(p+1)\) of them are equal to 1 by showing that \(\sum_i\lambda_i=n-(p+1)\): \[\sum_i\lambda_i=\mathrm{tr}(\boldsymbol D)=\mathrm{tr}(\boldsymbol D\boldsymbol\Gamma\boldsymbol\Gamma^T)=\mathrm{tr}(\boldsymbol\Gamma^T\boldsymbol D\boldsymbol\Gamma)=\mathrm{tr}(\boldsymbol I-\boldsymbol H)\] and \[\mathrm{tr}(\boldsymbol I-\boldsymbol H)=\mathrm{tr}(\boldsymbol I)-\mathrm{tr}(\boldsymbol H)=n-\mathrm{tr}(\boldsymbol X(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T)=n-\mathrm{tr}((\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\boldsymbol X)=n-(p+1)\] and we are done.

The next lines define the terms in the statement.

Trace \(\mathrm{tr}(\boldsymbol A)\): the sum of the diagonal entries of a square matrix \(\boldsymbol A\).
Two trace rules: \(\mathrm{tr}(\boldsymbol A-\boldsymbol B)=\mathrm{tr}(\boldsymbol A)-\mathrm{tr}(\boldsymbol B)\), and \(\mathrm{tr}(\boldsymbol A\boldsymbol B)=\mathrm{tr}(\boldsymbol B\boldsymbol A)\) when both products are square.

In words: the diagonal entries of \(\boldsymbol D\) are the \(\lambda_i\), so \(\sum_i\lambda_i=\mathrm{tr}(\boldsymbol D)\). The rule \(\mathrm{tr}(\boldsymbol A\boldsymbol B)=\mathrm{tr}(\boldsymbol B\boldsymbol A)\) gives \(\mathrm{tr}(\boldsymbol D)=\mathrm{tr}(\boldsymbol I-\boldsymbol H)\). The same rule changes \(\mathrm{tr}(\boldsymbol H)\) into the trace of a \((p+1)\times(p+1)\) identity matrix, which is \(p+1\).

  3. Calculate \(n-(p+1)\). This is the number of \(\lambda_i\) equal to 1.
  4. Calculate \(p+1\). This is the number of \(\lambda_i\) equal to 0.

04.6Recap: \(\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\sim\chi^2_{n-(p+1)}\) Slides p.43

This section puts the results of Sections 04.3, 04.4, and 04.5 together into the final result.

What Slides p.43

Lecture 7 · p.43 We showed:
1. \(\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e=\sum_{i=1}^nZ_i^2\) where \(Z_i\overset{indep}{\sim}N(0,\lambda_i)\).
  • i.e., a sum of \(n\) squared independent normally distributed r.v.'s
2. \(var(Z_i)=\lambda_i\in\{0,1\}\)
  • hence are either standard normally distributed or degenerate (0)
3. \(\sum_{i=1}^n\lambda_i=n-(p+1)\)
  • hence exactly \(n-(p+1)\) of the \(Z_i\) are \(N(0,1)\) r.v.s
\(\Longrightarrow\ \frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\) is a sum of \(n-(p+1)\) squared standard normal r.v.s \[\Longrightarrow\ \frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\sim\chi^2_{n-(p+1)}\]

In words: item 1 gives a sum of squared independent normal variables. Item 2 says that each term is standard normal or always 0. Item 3 says that exactly \(n-(p+1)\) terms are standard normal. Remove the terms that are always 0. The remaining sum fits the chi-squared definition with \(n-(p+1)\) degrees of freedom.

The unbiased estimator of Unit 02 is \(\hat\sigma^2=\frac{1}{n-(p+1)}\boldsymbol e^T\boldsymbol e\). Thus \(\boldsymbol e^T\boldsymbol e=(n-(p+1))\hat\sigma^2\), and the result is also \(\frac{(n-(p+1))\hat\sigma^2}{\sigma^2}\sim\chi^2_{n-(p+1)}\).

How Added

State the distribution of \(\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\) for a data set

  2. Calculate the degrees of freedom \(n-(p+1)\).
  3. Write \(\frac{1}{\sigma^2}\boldsymbol e^T\boldsymbol e\sim\chi^2_{n-(p+1)}\) with this number.
  4. If you need \(\hat\sigma^2\), divide \(\boldsymbol e^T\boldsymbol e\) by \(n-(p+1)\).

Self-check: The degrees of freedom of the chi-squared distribution must equal the divisor in \(\hat\sigma^2\).

05.1The t distribution of the standardized \(\hat\beta_j\) Slides p.44

This section gives the only theory result of the unit. All tests and intervals in the later sections use it.

What Slides p.44

In multiple linear regression · Lecture 7 · p.44 So we have \[\hat{\boldsymbol\beta}\sim N(\boldsymbol\beta,\sigma^2(\boldsymbol{X}^T\boldsymbol{X})^{-1})\implies\hat\beta_j\sim N(\beta_j,\sigma^2V_{jj})\implies\frac{\hat\beta_j-\beta_j}{\sqrt{\sigma^2V_{jj}}}\sim N(0,1)\] and when we estimate the variance with \(\hat\sigma^2=\frac{1}{n-(p+1)}\boldsymbol{e}^T\boldsymbol{e}\), we have: \[\frac{\hat\beta_j-\beta_j}{\sqrt{\hat\sigma^2V_{jj}}}\sim t_{n-(p+1)}\]

The first line says that one coefficient estimate \(\hat\beta_j\) has a normal distribution. Its mean is the true value \(\beta_j\). Its variance is \(\sigma^2V_{jj}\). When we subtract the mean and divide by the standard deviation, we get \(N(0,1)\). The standard deviation is the square root of the variance.

We do not know \(\sigma^2\). Thus the second line uses the estimate \(\hat\sigma^2\) in place of \(\sigma^2\). After this change, the distribution is \(t_{n-(p+1)}\) and not \(N(0,1)\). The number \(n-(p+1)\) is the degrees of freedom (d.o.f.). It is the number of observations minus the number of coefficients.

How Added

Write the t statistic for one coefficient \(\beta_j\)

  3. Calculate \(\hat\sigma^2=\boldsymbol e^T\boldsymbol e/(n-(p+1))\).
  4. Divide \(\hat\beta_j-\beta_j\) by \(\sqrt{\hat\sigma^2V_{jj}}\).
  5. Use \(n-(p+1)\) as the degrees of freedom of the t distribution.

05.4Inference rules for \(\beta_j\): test and confidence interval Slides p.47–49

This section shows that inference for \(\beta_j\) uses the same rules as simple linear regression (SLR). Only two items change: the standard error and the degrees of freedom.

What Slides p.47–49

First, we define four technical names. A hypothesis test uses data to decide if a statement about a parameter agrees with the data. The null hypothesis \(H_0:\beta_j=\theta_0\) is the statement that we test; \(\theta_0\) is a given number. \(t^{obs}\) is the value of the t statistic that we calculate from the observed data. A confidence interval (CI) is an interval, calculated from the data, that contains the true \(\beta_j\) with probability \(1-\alpha\).

Inference for \(\beta_j\) · Lecture 7 · p.47–49 We showed \(\dfrac{\hat\beta_j-\beta_j}{\sqrt{\hat\sigma^2V_{jj}}}\sim t_{n-(p+1)}\).
This is identical to the result for SLR except with updated
  • Standard errors: \(SE(\hat\beta_j)=\sqrt{\hat\sigma^2V_{jj}}\)
  • And the d.o.f. of the t distribution is \(n-(p+1)\)
    • Note: In SLR, we had \(n-2\), equivalent to \(p=1\) covariate

2. Confidence intervals:

Note on the slide text

Slides p.47–49 print \(SE(\hat\beta_j)=\hat\sigma^2V_{jj}\) without the square root. They also print \(t_{n-p+1}\) without the brackets. This page writes \(\sqrt{\hat\sigma^2V_{jj}}\) and \(t_{n-(p+1)}\). These forms agree with the formula on p.44 and with the standard errors \(\hat\sigma\sqrt{V_{jj}}\) on p.46.

The quantile \(t_{1-\alpha/2,\,n-(p+1)}\) is the point with area \(1-\alpha/2\) to its left under the \(t_{n-(p+1)}\) curve. The significance level \(\alpha\) is the largest probability of a wrong rejection that we accept. A usual value is \(\alpha=0.05\), which gives \(t_{0.975,\,n-(p+1)}\).

The null distribution is the distribution of the statistic when \(H_0\) is true. The p-value is the probability, under \(H_0\), of a value as far from 0 as \(t^{obs}\) or farther. A small p-value is evidence against \(H_0\). In SLR there is \(p=1\) covariate, thus \(n-(p+1)=n-2\).

How Added

Test \(H_0:\beta_j=\theta_0\)
  1. Write \(H_0:\beta_j=\theta_0\). The usual value is \(\theta_0=0\).
  2. Calculate \(t^{obs}=(\hat\beta_j-\theta_0)/\mathrm{SE}(\hat\beta_j)\).
  3. Use the null distribution \(T\sim t_{n-(p+1)}\).
  4. Calculate the p-value \(=2P(T>|t^{obs}|)\).
  5. Reject \(H_0\) if the p-value is less than \(\alpha\). The same rule: reject if \(|t^{obs}|>t_{1-\alpha/2,\,n-(p+1)}\).

Self-check: \(t^{obs}\) has the same sign as \(\hat\beta_j-\theta_0\). The p-value is between 0 and 1.

The value \(\theta_0=0\) means: covariate \(j\) has no linear relation with the mean response when the other covariates do not change.

Calculate the \(100(1-\alpha)\%\) confidence interval for \(\beta_j\)
  1. Find the quantile \(t_{1-\alpha/2,\,n-(p+1)}\) in a t table.
  2. Calculate the half-width \(t_{1-\alpha/2,\,n-(p+1)}\times\mathrm{SE}(\hat\beta_j)\).
  3. Write the interval \(\hat\beta_j\pm\) half-width.

Self-check: The midpoint of the interval is \(\hat\beta_j\). At the same \(\alpha\), the interval does not contain \(\theta_0\) exactly when the test rejects \(H_0:\beta_j=\theta_0\).

An estimate is a value that we calculate from the data in place of an unknown parameter. The estimate of \(\boldsymbol{a}^T\boldsymbol\beta\) is \(\boldsymbol{a}^T\hat{\boldsymbol\beta}\).
The standard error (SE) of an estimate is the estimated standard deviation of that estimate. The covariance of two random variables measures how they change together. The variance matrix \(\mathrm{Var}(\hat{\boldsymbol\beta})\) holds \(\mathrm{Var}(\hat\beta_j)\) at diagonal position \(j\). It holds \(\mathrm{Cov}(\hat\beta_j,\hat\beta_k)\) at off-diagonal position \((j,k)\). The rows and columns have the numbers 0 to \(p\).
