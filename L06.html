01.2 Matrix calculus Slides p.3

This section shows how to take the derivative of a scalar with respect to a vector. Unit 03 uses these two rules on the sum of squares \(S(\boldsymbol\beta)\).

What Slides p.3

A partial derivative \(\partial z/\partial y_j\) is the rate of change of \(z\) when only \(y_j\) changes. All other variables stay constant. The derivative with respect to a vector puts all the partial derivatives in one column. A symmetric matrix is a square matrix with \(\boldsymbol{A}^T=\boldsymbol{A}\). In a symmetric matrix, the entry in row \(i\), column \(j\) is equal to the entry in row \(j\), column \(i\).

Matrix Calculus · Lecture 6 · p.3 Let \(z=f(y_1,\dots,y_k)\) and \(\boldsymbol{y}=\left[\begin{array}{c}y_1\\ \vdots\\ y_k\end{array}\right]\), then \[\frac{\partial z}{\partial \boldsymbol{y}}=\left[\begin{array}{c}\frac{\partial z}{\partial y_1}\\ \frac{\partial z}{\partial y_2}\\ \vdots\\ \frac{\partial z}{\partial y_k}\end{array}\right]\]
  • If \(z=\boldsymbol{a}^T\boldsymbol{y}\), where \(\boldsymbol{a}=(a_1,\dots,a_k)^T\) is a vector, then \(\frac{\partial z}{\partial \boldsymbol{y}}=\boldsymbol{a}\)
  • If \(z=\boldsymbol{y}^T\boldsymbol{A}\boldsymbol{y}\) where \(\boldsymbol{A}\) is a \(k\times k\) matrix, then \(\frac{\partial z}{\partial \boldsymbol{y}}=\boldsymbol{A}\boldsymbol{y}+\boldsymbol{A}^T\boldsymbol{y}\)
    and if \(\boldsymbol{A}\) is symmetric, then: \(\frac{\partial z}{\partial \boldsymbol{y}}=2\boldsymbol{A}\boldsymbol{y}\)

Here \(z\) is a scalar, and \(\boldsymbol{y}\) holds \(k\) variables. Thus, \(\partial z/\partial\boldsymbol{y}\) is a \(k\times1\) column vector. Its entry \(j\) is \(\partial z/\partial y_j\). The scalar \(\boldsymbol{a}^T\boldsymbol{y}=a_1y_1+\dots+a_ky_k\) is a linear form: each \(y_j\) is multiplied by one constant. The scalar \(\boldsymbol{y}^T\boldsymbol{A}\boldsymbol{y}\) is a quadratic form: each term is a constant times two entries of \(\boldsymbol{y}\).

How Added

Use these steps to find \(\partial z/\partial\boldsymbol{y}\) for a given \(z\).

How · Take the derivative with respect to a vector
  1. Find the type of \(z\). If \(z=\boldsymbol{a}^T\boldsymbol{y}\), it is a linear form. If \(z=\boldsymbol{y}^T\boldsymbol{A}\boldsymbol{y}\), it is a quadratic form.
  2. For a linear form, write \(\partial z/\partial\boldsymbol{y}=\boldsymbol{a}\).
  3. For a quadratic form, compare each \(a_{ij}\) with \(a_{ji}\). If all pairs are equal, write \(2\boldsymbol{A}\boldsymbol{y}\). If not, write \(\boldsymbol{A}\boldsymbol{y}+\boldsymbol{A}^T\boldsymbol{y}\).
  4. Write the result as a \(k\times1\) column vector.

Self-check: The length of the result must be equal to the length \(k\) of \(\boldsymbol{y}\).

Self-check: Expand \(z\) as a usual polynomial. Find each \(\partial z/\partial y_j\). The result must agree with step 2 or step 3.

01.3 Properties of random vectors Slides p.4

This section restates the rules for the expectation and variance of a random vector. Unit 04 uses the last rule, \(\mathrm{Var}(\boldsymbol{A}\boldsymbol{y})=\boldsymbol{A}\mathrm{Var}(\boldsymbol{y})\boldsymbol{A}^T\), to find \(\mathrm{Var}[\hat{\boldsymbol\beta}]\).

What Slides p.4

A random variable is a number whose value comes from a random result. A random vector is a vector whose entries are random variables. The expectation \(E[\cdot]\) is the long-run average.

For a vector, take the expectation of each entry. The variance of a random variable is the expected squared distance from its expectation. The covariance \(\mathrm{cov}(y_i,y_j)=E[(y_i-E[y_i])(y_j-E[y_j])]\) shows how much two variables change together.

\(\mathrm{Var}(\boldsymbol{y})\) is the covariance matrix (the name from Lecture 5). Its entry in row \(i\), column \(j\) is \(\mathrm{cov}(y_i,y_j)\). Its diagonal holds the variance of each \(y_i\). Below, \(\boldsymbol{a}\), \(\boldsymbol{b}\), and \(\boldsymbol{A}\) are constants. They are not random.

Properties of Random Vectors · Lecture 6 · p.4
  • \(E[\boldsymbol{a}]=\boldsymbol{a}\)
  • \(E[\boldsymbol{a}^T\boldsymbol{y}+\boldsymbol{b}]=\boldsymbol{a}^TE[\boldsymbol{y}]+\boldsymbol{b}\)
  • \(E[\boldsymbol{A}\boldsymbol{y}]=\boldsymbol{A}E[\boldsymbol{y}]\)
  • \(\mathrm{Var}(\boldsymbol{y})=E[(\boldsymbol{y}-E[\boldsymbol{y}])(\boldsymbol{y}-E[\boldsymbol{y}])^T]\)
  • \(\mathrm{Var}(\boldsymbol{a}^T\boldsymbol{y})=\boldsymbol{a}^T\mathrm{Var}(\boldsymbol{y})\boldsymbol{a}\)
  • \(\mathrm{Var}(\boldsymbol{A}\boldsymbol{y})=\boldsymbol{A}\mathrm{Var}(\boldsymbol{y})\boldsymbol{A}^T\)

The expectation of a constant is the constant. The expectation moves through a constant matrix and through an added constant. For the variance, a constant matrix \(\boldsymbol{A}\) goes on the left, and \(\boldsymbol{A}^T\) goes on the right. \(\boldsymbol{a}^T\boldsymbol{y}\) is a scalar, so \(\mathrm{Var}(\boldsymbol{a}^T\boldsymbol{y})\) is a scalar. \(\boldsymbol{A}\boldsymbol{y}\) is a vector, so \(\mathrm{Var}(\boldsymbol{A}\boldsymbol{y})\) is a matrix.

How Added

Use these steps when you know \(E[\boldsymbol{y}]\) and \(\mathrm{Var}(\boldsymbol{y})\), and you must find the expectation and variance of \(\boldsymbol{A}\boldsymbol{y}\).

How · Expectation and variance after a linear change
  1. Write the constant matrix \(\boldsymbol{A}\) (\(m\times k\)), \(E[\boldsymbol{y}]\) (\(k\times1\)), and \(\mathrm{Var}(\boldsymbol{y})\) (\(k\times k\)).
  2. For the expectation, calculate \(\boldsymbol{A}E[\boldsymbol{y}]\). The result is \(m\times1\).
  3. For the variance, calculate \(\boldsymbol{A}\mathrm{Var}(\boldsymbol{y})\). Then multiply it on the right by \(\boldsymbol{A}^T\). The result is \(m\times m\).

Self-check: The variance matrix must be symmetric. Entry \((i,j)\) must be equal to entry \((j,i)\).

Self-check: The diagonal entries are variances. They must be \(\ge 0\).

01.4 Multivariate normal distribution Slides p.5

This section defines the multivariate normal distribution. The regression model on p.7 assumes that \(\boldsymbol\epsilon\) has this distribution, so \(\boldsymbol{y}\) also has it.

What Slides p.5

The standard normal \(N(0,1)\) is the normal distribution with mean 0 and variance 1. The abbreviation "i.i.d." means independent and identically distributed. Such variables are independent, and they have the same distribution. Two variables are independent if the value of one does not change the distribution of the other. The multivariate normal (MVN) is a distribution of a random vector. Its mean vector \(\boldsymbol\mu\) and its covariance matrix \(\boldsymbol\Sigma\) fully set the distribution.

The density \(f(\boldsymbol{y})\) is a function whose integral over a region gives the probability that \(\boldsymbol{y}\) is in that region. The determinant \(|\boldsymbol\Sigma|\) is one number that comes from a square matrix. For a 2×2 matrix, \(\left|\begin{array}{cc}p&q\\r&s\end{array}\right|=ps-qr\). The inverse \(\boldsymbol\Sigma^{-1}\) is the matrix with \(\boldsymbol\Sigma\boldsymbol\Sigma^{-1}=\boldsymbol{I}\).

Multivariate Normal Distribution · Lecture 6 · p.5 Let \(\boldsymbol{z}=(z_1,\dots,z_n)^T\) be a random vector of i.i.d standard normal random variables, i.e. \(z_i\overset{iid}{\sim}N(0,1)\).
Then \(\boldsymbol{y}=\boldsymbol{A}\boldsymbol{z}+\boldsymbol\mu\) has multivariate normal distribution, i.e.: \(\boldsymbol{y}\sim MVN(\boldsymbol\mu,\boldsymbol\Sigma)\) where \(E[\boldsymbol{y}]=\boldsymbol\mu\) and \(\mathrm{Var}(\boldsymbol{y})=\boldsymbol\Sigma=\boldsymbol{A}\boldsymbol{A}^T\).
\(\boldsymbol{y}\sim MVN(\boldsymbol\mu,\boldsymbol\Sigma)\), if: \[f(\boldsymbol{y})=\frac{1}{(2\pi)^{\frac n2}|\boldsymbol\Sigma|^{\frac12}}\exp\left\{-\frac12(\boldsymbol{y}-\boldsymbol\mu)^T\boldsymbol\Sigma^{-1}(\boldsymbol{y}-\boldsymbol\mu)\right\}\]

Slide p.5 gives two equivalent descriptions. The first description is a construction. It takes \(n\) independent standard normals, multiplies them by a constant matrix \(\boldsymbol{A}\), and adds a constant vector \(\boldsymbol\mu\). The result \(\boldsymbol{y}\) is multivariate normal. The second description is the density formula above. Both descriptions use only two parameters: the mean \(\boldsymbol\mu\) (\(n\times1\)) and the covariance matrix \(\boldsymbol\Sigma\) (\(n\times n\)).

How Added

Use these steps to get the distribution from the construction \(\boldsymbol{y}=\boldsymbol{A}\boldsymbol{z}+\boldsymbol\mu\), and to find the density at one point.

How · Get the MVN parameters and the density
  1. Read \(\boldsymbol\mu\). It is the constant vector that the construction adds.
  2. Calculate \(\boldsymbol\Sigma=\boldsymbol{A}\boldsymbol{A}^T\).
  3. Write \(\boldsymbol{y}\sim MVN(\boldsymbol\mu,\boldsymbol\Sigma)\).
  4. For \(f(\boldsymbol{y})\), calculate \(|\boldsymbol\Sigma|\), then \(\boldsymbol\Sigma^{-1}\), then \((\boldsymbol{y}-\boldsymbol\mu)^T\boldsymbol\Sigma^{-1}(\boldsymbol{y}-\boldsymbol\mu)\).
  5. Put these three values into the density formula.

Self-check: \(\boldsymbol\Sigma\) must be symmetric, and \(|\boldsymbol\Sigma|\) must be \(>0\). If not, \(|\boldsymbol\Sigma|^{1/2}\) and \(\boldsymbol\Sigma^{-1}\) do not exist.

Self-check: At \(\boldsymbol{y}=\boldsymbol\mu\), the quadratic form is 0, so the exponential term is \(e^0=1\).

01.5 Properties of \(\boldsymbol{y}\sim MVN(\boldsymbol\mu,\boldsymbol\Sigma)\) Slides p.6

This section gives four properties of the multivariate normal. Unit 04 uses the linearity property to get the distribution of \(\hat{\boldsymbol\beta}\).

What Slides p.6

A marginal distribution is the distribution of only some entries of a vector. A conditional distribution \(\boldsymbol{y}_1\mid\boldsymbol{y}_2\) is the distribution of \(\boldsymbol{y}_1\) when you know the value of \(\boldsymbol{y}_2\). \(\Sigma_{ij}\) is the entry of \(\boldsymbol\Sigma\) in row \(i\), column \(j\). It is equal to \(\mathrm{cov}(y_i,y_j)\).

Properties of \(\boldsymbol{y}\sim MVN(\boldsymbol\mu,\boldsymbol\Sigma)\) · Lecture 6 · p.6 Linearity: If \(\boldsymbol{u}=\boldsymbol{C}\boldsymbol{y}+\boldsymbol{d}\), then: \[\boldsymbol{u}\sim MVN(\boldsymbol{C}\boldsymbol\mu+\boldsymbol{d},\,\boldsymbol{C}\boldsymbol\Sigma\boldsymbol{C}^T)\] Marginal Distribution: If \(\tilde{\boldsymbol{y}}=(y_1,\dots,y_m)^T\subset\boldsymbol{y}\) is a vector subset of \(\boldsymbol{y}\), then \(\tilde{\boldsymbol{y}}\) is MVN-distributed.
Conditional Distribution: If \(\boldsymbol{y}=(\boldsymbol{y}_1^T,\boldsymbol{y}_2^T)^T\), then \(\boldsymbol{y}_1^T\mid\boldsymbol{y}_2^T\) is MVN-distributed.
Independence: If \(\Sigma_{ij}=0\), then \(\boldsymbol{y}_i\) and \(\boldsymbol{y}_j\) are independent.

Each property in one sentence:

Linearity: a multivariate normal vector, multiplied by a constant matrix \(\boldsymbol{C}\) and added to a constant vector \(\boldsymbol{d}\), stays multivariate normal. Its mean and variance change by the rules of p.4.
Marginal: any set of entries from a multivariate normal vector is multivariate normal. One single entry has a one-dimensional normal distribution.
Conditional: divide \(\boldsymbol{y}\) into an upper block \(\boldsymbol{y}_1\) and a lower block \(\boldsymbol{y}_2\). When \(\boldsymbol{y}_2\) is known, \(\boldsymbol{y}_1\) is multivariate normal. The slide writes \(\boldsymbol{y}_1^T\mid\boldsymbol{y}_2^T\), with transposes, and this has the same meaning as \(\boldsymbol{y}_1\mid\boldsymbol{y}_2\). This lecture does not give the parameters of the conditional distribution.
Independence: for a multivariate normal vector, covariance 0 gives independence.

How Added

Use these steps when \(\boldsymbol{y}\sim MVN(\boldsymbol\mu,\boldsymbol\Sigma)\) is known, and you must find the distribution of a linear combination or a subset. A linear combination is a sum of the entries, each multiplied by a constant.

01.6 Recap: multiple linear regression Slides p.7

This section writes the multiple linear regression model first as one matrix equation, then as one multivariate normal distribution. Units 02 to 05 all start from this form.

What Slides p.7

Multiple linear regression (MLR) is a model for an outcome \(y_i\). The outcome is an intercept plus a linear combination of \(p\) covariates \(x_{i1},\dots,x_{ip}\), plus a random error \(\epsilon_i\). The regression coefficients \(\beta_0,\dots,\beta_p\) are unknown constants. The error variance \(\sigma^2\) is also an unknown constant. \(n\) is the number of observations.

Recap: Multiple Linear Regression · Lecture 6 · p.7 \[y_i=\beta_0+\beta_1x_{i1}+\cdots+\beta_Px_{ip}+\epsilon_i,\qquad \epsilon_i\overset{iid}{\sim}N(0,\sigma^2)\] We can write this: \[\left[\begin{array}{c}y_1\\y_2\\ \vdots\\y_n\end{array}\right]=\left[\begin{array}{cccccc}1&x_{11}&x_{12}&\dots&x_{1p}\\1&x_{21}&x_{22}&\dots&x_{2p}\\ \vdots&\vdots&\vdots&\vdots&\vdots\\1&x_{n1}&x_{n2}&\dots&x_{np}\end{array}\right]\left[\begin{array}{c}\beta_0\\ \beta_1\\ \vdots\\ \beta_p\end{array}\right]+\left[\begin{array}{c}\epsilon_1\\ \epsilon_2\\ \vdots\\ \epsilon_n\end{array}\right]\] Or more simply: \[\begin{array}{rl}&\boldsymbol{y}=\boldsymbol{X}\boldsymbol\beta+\boldsymbol\epsilon,\qquad \boldsymbol\epsilon\sim MVN(\boldsymbol{0},\sigma^2\boldsymbol{I})\\ \iff&\boldsymbol{y}\sim MVN(\boldsymbol{X}\boldsymbol\beta,\sigma^2\boldsymbol{I})\end{array}\]
Notation note The first line of the slide writes \(\beta_P\) with an upper-case P. The subscript in \(x_{ip}\) and the last entry \(\beta_p\) of the vector use a lower-case p. This page copies the slide. Both letters mean the same number: the index \(p\) of the last covariate.

Each row \(i\) is one observation. The first column of \(\boldsymbol{X}\) contains only 1s. This column multiplies \(\beta_0\) and gives the intercept. Column \(j+1\) of \(\boldsymbol{X}\) is covariate \(j\). Thus, \(\boldsymbol{X}\) is \(n\times(p+1)\), and \(\boldsymbol\beta\) is \((p+1)\times1\).

The statement "\(\epsilon_i\) i.i.d. \(N(0,\sigma^2)\)" is equal to \(\boldsymbol\epsilon\sim MVN(\boldsymbol{0},\sigma^2\boldsymbol{I})\): all means are 0, all variances are \(\sigma^2\), and all covariances between different observations are 0.

Figure 1-2. The size of each block in \(\boldsymbol{y}=\boldsymbol{X}\boldsymbol\beta+\boldsymbol\epsilon\). The first column of \(\boldsymbol{X}\) (left of the dashed line) contains only 1s, for the intercept \(\beta_0\). The number of columns of \(\boldsymbol{X}\) is equal to the length \(p+1\) of \(\boldsymbol\beta\). Thus, the product exists, and its size is \(n\times1\).

How Added

Use these steps to write the matrix form from the \(n\) equations.

How · Write \(\boldsymbol{y}=\boldsymbol{X}\boldsymbol\beta+\boldsymbol\epsilon\)
  1. For \(\boldsymbol{y}\), put \(y_1,\dots,y_n\) in one column.
  2. For \(\boldsymbol{X}\), write \((1,x_{i1},\dots,x_{ip})\) as row \(i\).
  3. For \(\boldsymbol\beta\), put \(\beta_0,\dots,\beta_p\) in one column.
  4. Multiply row \(i\) of \(\boldsymbol{X}\) by \(\boldsymbol\beta\). The result must be \(\beta_0+\beta_1x_{i1}+\dots+\beta_px_{ip}\) from equation \(i\).

Self-check: \(\boldsymbol{X}\) has \(n\) rows and \(p+1\) columns. Its first column contains only 1s.

02.6 The multiple linear regression model Slides p.13

This section gives the model of this lecture. The slides write it in two equivalent forms: a scalar form for each observation and a matrix form for all observations.

What Slides p.13

Multiple Linear Regression · Lecture 6 · p.13 \[y_i=\beta_0+\beta_1x_{i1}+\cdots+\beta_Px_{ip}+\epsilon_i,\qquad \epsilon_i\overset{iid}{\sim}N(0,\sigma^2),\quad i=1,\dots,n\]

Or

\[\boldsymbol{y}=\boldsymbol{X}\boldsymbol{\beta}+\boldsymbol{\epsilon},\quad \boldsymbol{\epsilon}\sim MVN(\boldsymbol{0},\sigma^2\boldsymbol{I})\] \[\iff\] \[\boldsymbol{y}\sim MVN(\boldsymbol{X}\boldsymbol{\beta},\sigma^2\boldsymbol{I})\]

Note: we assume \(p+1<n\)

The list below defines each symbol of the model.

\(\beta_0\): the intercept. It is an unknown fixed number.

\(\beta_1,\dots,\beta_p\): the regression coefficients, one for each covariate. They are unknown fixed numbers. The slide writes the last term as \(\beta_Px_{ip}\). The capital \(P\) means the coefficient number \(p\).

\(\epsilon_i\): the error. It is the random part of \(y_i\) that is not in \(\beta_0+\beta_1x_{i1}+\cdots+\beta_px_{ip}\).

\(\epsilon_i\overset{iid}{\sim}N(0,\sigma^2)\): the errors are independent and identically distributed. Each error has a normal distribution with mean 0 and variance \(\sigma^2\).

\(\boldsymbol{y}\) and \(\boldsymbol{\epsilon}\): \(n\times1\) column vectors of the outcomes and the errors.

\(\boldsymbol{\beta}=(\beta_0,\beta_1,\dots,\beta_p)^T\): the \((p+1)\times1\) vector of coefficients.

Design matrix \(\boldsymbol{X}\): an \(n\times(p+1)\) matrix. Row \(i\) is \((1,x_{i1},\dots,x_{ip})\). The first column is all 1s, for the intercept.

\(MVN(\boldsymbol{0},\sigma^2\boldsymbol{I})\): a multivariate normal distribution with mean vector \(\boldsymbol{0}\) and covariance matrix \(\sigma^2\boldsymbol{I}\). Each error has variance \(\sigma^2\), and different errors are uncorrelated.

\(p+1<n\): the number of unknown coefficients, \(p+1\), is less than the number of observations, \(n\). Unit 05 divides by \(n-(p+1)\), and this assumption makes that number positive.

How Added

  1. Find the outcome \(y_i\) and the \(p\) covariates. Write \(n\) and \(p\).

What Slides p.14–16

Interpreting Regression Coefficients · Lecture 6 · p.14–16

To interpret a parameter, isolate it!

\[E[y_i\,|\,x_{i1},\dots,x_{ip}]=\beta_0+\beta_1x_{i1}\cdots+\beta_Px_{ip}\]

What does \(\beta_0\) represent?

\[E[y_i\,|\,x_{i1}=\cdots=x_{ip}=0]=\beta_0+\beta_1(0)+\cdots+\beta_P(0)=\beta_0\]
  • \(\implies\beta_0\) is the mean outcome when all covariates are set to 0
  • May not be interpretable: e.g. what does it mean for age to be 0 in a sample of adults?

What does \(\beta_1\) represent?

\[E[y_i\,|\,x_{i1}=x_1,x_{i2}=x_2,\dots,x_{ip}=x_P]=\beta_0+\beta_1(x_1)+\beta_2(x_2)+\cdots+\beta_P(x_P)\] \[E[y_i\,|\,x_{i1}=(x_1+1),x_{i2}=x_2,\dots,x_{ip}=x_P]=\beta_0+\beta_1(x_1+1)+\cdots+\beta_P(x_P)\]
  • \(E[y_i\,|\,x_{i1}=(x_1+1),x_{i2}=x_2,\dots,x_{ip}=x_P]-E[y_i\,|\,x_{i1}=x_1,x_{i2}=x_2,\dots,x_{ip}=x_P]=\beta_1\)
  • More generally \(\beta_j\) represents the difference in mean outcome for a one-unit change in the \(j^{th}\) covariate, holding other covariates fixed.

Conditional expectation \(E[y_i\,|\,x_{i1},\dots,x_{ip}]\): the mean of \(y_i\) when the covariates have the given values. Read the bar \(|\) as "given".

\(\beta_0\): the mean outcome when all covariates are 0. If 0 is not in the range of the data, \(\beta_0\) has no practical meaning.

\(\beta_1\): the difference in mean outcome when covariate 1 increases by one unit and the other covariates do not change.

\(\beta_j\): the difference in mean outcome when covariate \(j\) increases by one unit and the other covariates do not change.

The words "holding other covariates fixed" are a necessary part of the interpretation. They agree with "conditional on" and "with the same" in Questions 1 and 2 of Section 02.5.

How Added

Interpret one coefficient \(\beta_j\)
  1. Write the full conditional expectation \(\beta_0+\beta_1x_{i1}+\cdots+\beta_px_{ip}\).
  2. For the intercept: put 0 for all covariates. The result is \(\beta_0\).
  3. Check in the summary table if 0 is in the range of each covariate.
  4. For a slope: write the conditional expectation two times, with covariate \(j\) equal to \(x_j\) and \(x_j+1\).
  5. Give the other covariates the same values in both expressions.
  6. Subtract the first expression from the second. Only \(\beta_j\) remains.
  7. Write the interpretation: a one-unit increase in covariate \(j\) changes the mean outcome by \(\beta_j\), with other covariates held fixed.

Self-check: The interpretation names the covariate and its unit. It gives the direction and size of \(\beta_j\). It says that the other covariates are held fixed. With an estimate, it says "estimated mean outcome".

03.1 Title page: Estimating \(\boldsymbol\beta\) Slides p.17

Slide p.17 shows only the title "Estimating \(\boldsymbol\beta\)". This unit uses the model \(\boldsymbol{y}=\boldsymbol{X}\boldsymbol\beta+\boldsymbol\epsilon\) with \(\boldsymbol\epsilon\sim MVN(\boldsymbol{0},\sigma^2\boldsymbol{I})\). The next lines give each symbol again.

\(\boldsymbol{y}\) is the \(n\times1\) outcome vector. It holds the outcome \(y_i\) of each of the \(n\) observations.
\(\boldsymbol{X}\) is the \(n\times(p+1)\) design matrix. Its first column is all 1s. The other \(p\) columns hold the covariates.
\(\boldsymbol\beta=(\beta_0,\dots,\beta_p)^T\) is the unknown coefficient vector. \(\boldsymbol\epsilon\) is the \(n\times1\) vector of random errors.
\(MVN(\boldsymbol{0},\sigma^2\boldsymbol{I})\) is the multivariate normal distribution with mean vector \(\boldsymbol{0}\) and covariance matrix \(\sigma^2\boldsymbol{I}\). Thus, the errors are independent normal, each with variance \(\sigma^2\).
Estimator \(\hat{\boldsymbol\beta}\): a formula that uses the data \(\boldsymbol{y}\) and \(\boldsymbol{X}\) to give a value for the unknown \(\boldsymbol\beta\). The hat \(\hat{\ }\) means "calculated from the data".

The slides use the satisfaction data: \(n=46\) patients and three covariates (Age, Severity, Stress), so \(p=3\) (Slides p.9). The example in this unit uses a smaller data set so that you can do each step by hand. Section 03.2 now uses least squares to find \(\hat{\boldsymbol\beta}\).

03.2 Least squares estimation Slides p.18–20

This section finds the \(\boldsymbol\beta\) that makes the total squared difference between the data \(\boldsymbol{y}\) and the model values \(\boldsymbol{X}\boldsymbol\beta\) as small as possible. Slides p.18–19 build up p.20 line by line, so p.20 holds all of the content.

What Slides p.20

Least Squares Estimation · Lecture 6 · p.20 Want to minimize the sum of squares, i.e.: \[\begin{aligned} S(\boldsymbol\beta)&=(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)^T(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)\\ &=\boldsymbol{y}^T\boldsymbol{y}-\boldsymbol{y}^T\boldsymbol{X}\boldsymbol\beta-\boldsymbol\beta^T\boldsymbol{X}^T\boldsymbol{y}+\boldsymbol\beta^T\boldsymbol{X}^T\boldsymbol{X}\boldsymbol\beta\\ &=\boldsymbol{y}^T\boldsymbol{y}-2\boldsymbol{y}^T\boldsymbol{X}\boldsymbol\beta+\boldsymbol\beta^T\boldsymbol{X}^T\boldsymbol{X}\boldsymbol\beta \end{aligned}\] \[\begin{aligned} \frac{\partial S(\boldsymbol\beta)}{\partial\boldsymbol\beta}=-2\boldsymbol{X}^T\boldsymbol{y}+2\boldsymbol{X}^T\boldsymbol{X}\boldsymbol\beta&=0\\ (\boldsymbol{X}^T\boldsymbol{X})\boldsymbol\beta&=\boldsymbol{X}^T\boldsymbol{y}\\ \hat{\boldsymbol\beta}&=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{y} \end{aligned}\] assuming the columns of \(\boldsymbol{X}\) are linearly independent

The next lines define each new term in the statement.

Sum of squares \(S(\boldsymbol\beta)\): for one candidate \(\boldsymbol\beta\), square each difference \(y_i-(\boldsymbol{X}\boldsymbol\beta)_i\) and add the squares. Thus, \(S(\boldsymbol\beta)=\sum_{i=1}^n\big(y_i-(\boldsymbol{X}\boldsymbol\beta)_i\big)^2\). It is one number.
Least squares estimation: use the \(\boldsymbol\beta\) that gives the smallest \(S(\boldsymbol\beta)\) as the estimate \(\hat{\boldsymbol\beta}\). This estimate is also named OLS (ordinary least squares).
Derivative with respect to a vector \(\partial S(\boldsymbol\beta)/\partial\boldsymbol\beta\): the partial derivatives of \(S\) with respect to \(\beta_0,\dots,\beta_p\), in one \((p+1)\times1\) column. At the minimum of \(S\), this column is 0.
Inverse matrix \(\boldsymbol{A}^{-1}\): the square matrix with \(\boldsymbol{A}^{-1}\boldsymbol{A}=\boldsymbol{I}\). The identity matrix \(\boldsymbol{I}\) has 1s on the diagonal and 0s at all other positions.
Linearly independent columns: no column of \(\boldsymbol{X}\) is a linear combination of the other columns. Then \(\boldsymbol{X}^T\boldsymbol{X}\) has an inverse, and \(\hat{\boldsymbol\beta}\) is unique.

In words: set the derivative of \(S(\boldsymbol\beta)\) to 0. This gives the system of equations \((\boldsymbol{X}^T\boldsymbol{X})\boldsymbol\beta=\boldsymbol{X}^T\boldsymbol{y}\). These equations are the normal equations. When the columns of \(\boldsymbol{X}\) are linearly independent, the system has one solution, \(\hat{\boldsymbol\beta}=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{y}\).

How Added

Calculate \(\hat{\boldsymbol\beta}\) from data
  1. Write \(\boldsymbol{y}\) (\(n\times1\)) and \(\boldsymbol{X}\) (\(n\times(p+1)\), first column all 1s).
  2. Calculate the \((p+1)\times(p+1)\) matrix \(\boldsymbol{X}^T\boldsymbol{X}\). Entry \((j,k)\) is \(\sum_i x_{ij}x_{ik}\) for columns \(j\) and \(k\).
  3. Calculate the \((p+1)\times1\) vector \(\boldsymbol{X}^T\boldsymbol{y}\). Entry \(j\) is \(\sum_i x_{ij}y_i\) for column \(j\).
  4. Make sure that \(\det(\boldsymbol{X}^T\boldsymbol{X})\neq0\). This shows that the columns of \(\boldsymbol{X}\) are linearly independent.
  5. Solve \((\boldsymbol{X}^T\boldsymbol{X})\boldsymbol\beta=\boldsymbol{X}^T\boldsymbol{y}\). The solution is \(\hat{\boldsymbol\beta}\).

Self-check: (1) \(\boldsymbol{X}^T\boldsymbol{X}\) is symmetric, and its entry \((1,1)\) is \(n\). (2) Entry 1 of \(\boldsymbol{X}^T\boldsymbol{y}\) is \(\sum_iy_i\). (3) Put \(\hat{\boldsymbol\beta}\) back: \((\boldsymbol{X}^T\boldsymbol{X})\hat{\boldsymbol\beta}\) must equal \(\boldsymbol{X}^T\boldsymbol{y}\).

What Slides p.22

Maximum Likelihood · Lecture 6 · p.22 Under our assumptions, we have: \[\boldsymbol{y}\sim MVN(\boldsymbol{X}\boldsymbol\beta,\sigma^2\boldsymbol{I})\] \[\mathcal{L}(\boldsymbol\beta,\sigma^2|\mathbf{Y})=\frac{1}{(2\pi)^{\frac n2}|\sigma^2\boldsymbol{I}|^{\frac12}}\exp\left\{-\frac12(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)^T(\sigma^2\boldsymbol{I})^{-1}(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)\right\}\] \[\ell(\boldsymbol\beta,\sigma^2|\mathbf{Y})=-\frac n2\log(2\pi)-\frac n2\log\sigma^2-\frac{1}{2\sigma^2}(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)^T(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)\] Look familiar?

• I.e. MLE=OLS (when all our assumptions hold)

The next lines define each new term in the statement.

\(\mathcal{L}\) is the MVN density with mean \(\boldsymbol{X}\boldsymbol\beta\) and covariance matrix \(\sigma^2\boldsymbol{I}\).
Likelihood \(\mathcal{L}(\boldsymbol\beta,\sigma^2|\mathbf{Y})\): put the observed data into the density, and read the result as a function of the parameters \(\boldsymbol\beta\) and \(\sigma^2\). The bar before \(\mathbf{Y}\) means "the data are given".
Log-likelihood \(\ell(\boldsymbol\beta,\sigma^2|\mathbf{Y})\): \(\log\mathcal{L}\), with the natural logarithm. The function \(\log\) increases, so \(\ell\) and \(\mathcal{L}\) have their maximum at the same point.
Maximum likelihood estimator (MLE) \(\hat{\boldsymbol\beta}_{MLE}\): the \(\boldsymbol\beta\) that gives the largest \(\mathcal{L}\), and thus the largest \(\ell\).

In words: only the last term of \(\ell\) contains \(\boldsymbol\beta\). That term is \(-\frac{1}{2\sigma^2}S(\boldsymbol\beta)\). This is the meaning of "Look familiar?". The largest \(\ell\) occurs at the smallest \(S(\boldsymbol\beta)\), so MLE and OLS give the same \(\hat{\boldsymbol\beta}\). This is true when all model assumptions hold: linearity, independence, normality, and equal variance.

How Added

Get \(\hat{\boldsymbol\beta}_{MLE}\) from the model

04.1 The mean of \(\hat{\boldsymbol\beta}\): unbiasedness Slides p.23–25

This section shows that the mean of \(\hat{\boldsymbol\beta}\) is equal to the true value \(\boldsymbol\beta\).

What Slides p.25

Properties of \(\hat{\boldsymbol\beta}\) · Lecture 6 · p.25 \[E[\hat{\boldsymbol\beta}]=E[(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\boldsymbol y]=\boldsymbol\beta\]

The vector \(\boldsymbol y\) is random. Thus \(\hat{\boldsymbol\beta}\), which we calculate from \(\boldsymbol y\), is also random. A new data set gives a different \(\hat{\boldsymbol\beta}\). The statement says that the mean of \(\hat{\boldsymbol\beta}\) over all possible data sets is exactly \(\boldsymbol\beta\). This property has the name "unbiased": the mean of the estimator is equal to the parameter that it estimates.

The reason is short. \(\hat{\boldsymbol\beta}\) is a constant matrix times \(\boldsymbol y\), and that constant matrix times \(\boldsymbol X\) is \(\boldsymbol I\).

How Added

Find if an estimator of the form \(\boldsymbol C\boldsymbol y\) is unbiased
  1. Write the estimator as \(\boldsymbol C\boldsymbol y\). \(\boldsymbol C\) must contain only \(\boldsymbol X\) and numbers.
  2. For \(\hat{\boldsymbol\beta}\), use \(\boldsymbol C=(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\).
  3. Move \(E\) inside: \(E[\boldsymbol C\boldsymbol y]=\boldsymbol C\,E[\boldsymbol y]\).
  4. Put in \(E[\boldsymbol y]=\boldsymbol X\boldsymbol\beta\) from the model. The result is \(\boldsymbol C\boldsymbol X\boldsymbol\beta\).
  5. Calculate \(\boldsymbol C\boldsymbol X\). If \(\boldsymbol C\boldsymbol X=\boldsymbol I\), then \(E[\boldsymbol C\boldsymbol y]=\boldsymbol\beta\).

Self-check: \(\boldsymbol C\) is \((p+1)\times n\). \(\boldsymbol C\boldsymbol X\) is \((p+1)\times(p+1)\). Each entry of \(\boldsymbol C\boldsymbol X\) must be exactly 1 on the diagonal and 0 off the diagonal.

04.2 The covariance matrix of \(\hat{\boldsymbol\beta}\) Slides p.26–27

This section finds the covariance matrix of \(\hat{\boldsymbol\beta}\). This matrix gives the variance of each \(\hat\beta_j\). Later units use it to make confidence intervals.

What Slides p.27

Properties of \(\hat{\boldsymbol\beta}\) · Lecture 6 · p.27 \[\mathrm{Var}[\hat{\boldsymbol\beta}]=\mathrm{Var}[(\boldsymbol X^T\boldsymbol X)^{-1}\boldsymbol X^T\boldsymbol y]=\sigma^2(\boldsymbol X^T\boldsymbol X)^{-1}\]

The variance of a random variable is the mean squared distance from its mean. \(\mathrm{Var}[\hat{\boldsymbol\beta}]\) is a \((p+1)\times(p+1)\) matrix. Its diagonal entry for \(\beta_j\) is the variance of \(\hat\beta_j\). The matrix is a product of two parts: the unknown error variance \(\sigma^2\) and the known matrix \((\boldsymbol X^T\boldsymbol X)^{-1}\).

The slides write \(\boldsymbol V=(\boldsymbol X^T\boldsymbol X)^{-1}\) (p.29). The rows and columns of \(\boldsymbol V\) follow the order \(\beta_0,\beta_1,\dots,\beta_p\). \(V_{jj}\) is the diagonal entry of \(\boldsymbol V\) for \(\beta_j\).

How Added

Find \(\mathrm{Var}[\hat\beta_j]\)
  1. Make the design matrix \(\boldsymbol X\). Put 1 in each entry of column 1.
  2. Calculate \(\boldsymbol X^T\boldsymbol X\).
  3. Find the inverse \(\boldsymbol V=(\boldsymbol X^T\boldsymbol X)^{-1}\).
  4. Take the diagonal entry \(V_{jj}\) for \(\beta_j\). The first diagonal entry is for \(\beta_0\).
  5. Write \(\mathrm{Var}[\hat\beta_j]=\sigma^2V_{jj}\).

Self-check: \(\boldsymbol V\) is \((p+1)\times(p+1)\). \(\boldsymbol V\) is symmetric, so \(V_{jk}=V_{kj}\). Each \(V_{jj}\) must be larger than 0, because a variance is not negative.

04.5 Residuals and \(\boldsymbol X^T\boldsymbol e=\boldsymbol 0\) Slides p.31–32

This section defines the residual vector and writes it as \((\boldsymbol I-\boldsymbol H)\boldsymbol y\). Then it shows that the residual vector is orthogonal to each column of \(\boldsymbol X\).

What Slides p.32

Residuals · Lecture 6 · p.32 \[\boldsymbol e=\boldsymbol y-\hat{\boldsymbol y}=(\boldsymbol I-\boldsymbol H)\boldsymbol y.\] Note: \(\boldsymbol X^T\boldsymbol e=\boldsymbol 0\). Why?

A residual \(e_i\) is the observed value minus the fitted value: \(e_i=y_i-\hat y_i\). The vector \(\boldsymbol e=(e_1,\dots,e_n)^T\) holds the \(n\) residuals. \(\boldsymbol X^T\boldsymbol e=\boldsymbol 0\) is a set of \(p+1\) equations. Each equation comes from one column of \(\boldsymbol X\).

Column 1 has all entries equal to 1. Thus equation 1 is \(\sum_{i=1}^n e_i=0\): the residuals add to 0.
Column \(k+1\) holds covariate \(k\). Thus its equation is \(\sum_{i=1}^n x_{ik}e_i=0\).

Two vectors are orthogonal when their dot product is 0. The dot product is the sum of the products of matching entries. Thus \(\boldsymbol X^T\boldsymbol e=\boldsymbol 0\) means that \(\boldsymbol e\) is orthogonal to each column of \(\boldsymbol X\).

How Added

Calculate the residuals and check \(\boldsymbol X^T\boldsymbol e=\boldsymbol 0\)

  2. Subtract for each \(i\): \(e_i=y_i-\hat y_i\).
  3. Add the residuals: \(\sum e_i\).
  4. For each covariate \(k\), calculate \(\sum x_{ik}e_i\).

Self-check: \(\boldsymbol X^T\boldsymbol e\) has \(p+1\) entries. With exact arithmetic, each entry is exactly 0.

05.1 MLE of \(\sigma^2\) Slides p.33–35

This section finds the number that estimates \(\sigma^2\) when \(\hat{\boldsymbol\beta}\) is known. The method is the same as for \(\boldsymbol\beta\): write the log-likelihood, take its derivative, and set the derivative to zero.

What Slides p.35

The likelihood is the probability density of the observed data, read as a function of the parameters. The log-likelihood \(\ell\) is the natural log of the likelihood. The maximum likelihood estimate (MLE) is the parameter value that makes \(\ell\) as large as possible.

MLE of σ² · Lecture 6 · p.35 \[\ell(\boldsymbol\beta,\sigma^2\mid\boldsymbol{y})=-\frac n2\log(2\pi)-\frac n2\log\sigma^2-\frac{1}{2\sigma^2}(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)^T(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)\] \[\frac{\partial\ell(\boldsymbol\beta,\sigma^2\mid\boldsymbol{y})}{\partial\sigma^2}=-\frac{n}{2\sigma^2}+\frac{1}{2(\sigma^2)^2}(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)^T(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)=0\] \[(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)^T(\boldsymbol{y}-\boldsymbol{X}\boldsymbol\beta)=n\sigma^2\] \[\Longrightarrow\ \hat\sigma^2_{MLE}=\frac1n(\boldsymbol{y}-\boldsymbol{X}\hat{\boldsymbol\beta})^T(\boldsymbol{y}-\boldsymbol{X}\hat{\boldsymbol\beta})\]

The vector \(\boldsymbol{y}-\boldsymbol{X}\hat{\boldsymbol\beta}\) is the residual vector \(\boldsymbol{e}\). Thus \(\hat\sigma^2_{MLE}=\frac1n\boldsymbol{e}^T\boldsymbol{e}\). In words, the MLE is the residual sum of squares divided by \(n\). This is the mean of the squared residuals.

The partial derivative \(\partial\ell/\partial\sigma^2\) treats \(\boldsymbol\beta\) as a constant and takes the derivative only with respect to \(\sigma^2\). Slides p.34 show the same page with the derivative empty. Slides p.35 show the full result.

How Added

Calculate \(\hat\sigma^2_{MLE}\)
  1. Calculate the fitted values: \(\hat y_i=\hat\beta_0+\hat\beta_1x_i\) for each \(i\). In matrix form, \(\hat{\boldsymbol{y}}=\boldsymbol{X}\hat{\boldsymbol\beta}\).
  2. Calculate the residuals: \(e_i=y_i-\hat y_i\).
  3. Square each residual. Add the squares to get \(\boldsymbol{e}^T\boldsymbol{e}\).
  4. Divide by \(n\): \(\hat\sigma^2_{MLE}=\boldsymbol{e}^T\boldsymbol{e}/n\).

Self-check: \(\boldsymbol{e}^T\boldsymbol{e}\) is a sum of squares, so it must be \(\ge0\). Also, \(\boldsymbol{X}^T\boldsymbol{e}\) must be \(\boldsymbol{0}\) (Slides p.32). If not, \(\hat{\boldsymbol\beta}\) has an error.

05.2 Unbiased estimate of \(\sigma^2\) Slides p.36

This section changes the divisor from \(n\) to \(n-(p+1)\). It gives the definition, then a calculation, then the reason for the new divisor.

What Slides p.36

An estimator is a formula that uses the data to give a value for an unknown parameter. It is random, because the data are random. The bias of an estimator \(\hat\theta\) is \(E[\hat\theta]-\theta\). An estimator is unbiased when its bias is zero, so \(E[\hat\theta]=\theta\).

Unbiased estimate of σ² · Lecture 6 · p.36 The MLE of \(\sigma^2\) is \(\frac1n\boldsymbol{e}^T\boldsymbol{e}\), where \(\boldsymbol{e}=\boldsymbol{y}-\boldsymbol{X}\hat{\boldsymbol\beta}\).
Instead we usually use \(\hat\sigma^2=\frac{1}{n-(p+1)}\boldsymbol{e}^T\boldsymbol{e}\). Why?

The two estimates have the same numerator, \(\boldsymbol{e}^T\boldsymbol{e}\). Only the divisor is different. The number \(n-(p+1)=n-p-1\) is the residual degrees of freedom. It is the number of residuals that can change freely. On this page, \(\hat\sigma^2\) without a subscript means this unbiased estimate.

How Added

Calculate \(\hat\sigma^2\)
  1. Calculate \(\boldsymbol{e}^T\boldsymbol{e}\) with steps 1–3 of Section 05.1.
  2. Count the coefficients. \(p\) is the number of covariates. \(p+1\) is the number of coefficients, with the intercept.
  3. Calculate the degrees of freedom: \(n-p-1\).
  4. Divide: \(\hat\sigma^2=\boldsymbol{e}^T\boldsymbol{e}/(n-p-1)\).

Self-check: \(n-p-1<n\), so \(\hat\sigma^2\) must be larger than \(\hat\sigma^2_{MLE}\). The ratio \(\hat\sigma^2/\hat\sigma^2_{MLE}\) must be \(n/(n-p-1)\).

Why Added

Slides p.36 ask "Why?" but do not give a proof. Two facts from the slides show why the divisor is \(n-(p+1)\).

1
\[\boldsymbol{X}^T\boldsymbol{e}=\boldsymbol{0}\]

Result of p.32. The matrix \(\boldsymbol{X}^T\) has \(p+1\) rows.

2
\[\sum_{i=1}^n x_{ij}e_i=0,\qquad j=0,1,\dots,p\]

Write step 1 row by row. The first column of \(\boldsymbol{X}\) is all ones, so row \(j=0\) gives \(\sum e_i=0\). These are \(p+1\) linear constraints on \(e_1,\dots,e_n\).

3
\[\text{number of free residuals}=n-(p+1)\]

The \(n\) residuals must satisfy \(p+1\) constraints. If you choose \(n-(p+1)\) residuals, the constraints fix the other \(p+1\).

4
\[\hat\sigma^2=\frac{\boldsymbol{e}^T\boldsymbol{e}}{n-(p+1)}\]

Each estimated coefficient uses one degree of freedom. Thus \(\boldsymbol{e}^T\boldsymbol{e}\) holds only \(n-(p+1)\) free pieces of information. This divisor gives \(E[\hat\sigma^2]=\sigma^2\) (proof in the optional block below). ∎

In the example, the \(p+1=2\) constraints are \(\sum e_i=0\) and \(\sum x_ie_i=0\). Section 5.1 showed both. If you know \(e_1,e_2,e_3\), the two constraints fix \(e_4\) and \(e_5\). Thus only \(5-2=3\) residuals are free.

Optional — not on the slides · Proof that \(E[\boldsymbol{e}^T\boldsymbol{e}]=(n-p-1)\sigma^2\)

This proof uses the trace \(\mathrm{tr}(\boldsymbol{A})\), which is the sum of the diagonal entries of a square matrix. The trace has the property \(\mathrm{tr}(\boldsymbol{AB})=\mathrm{tr}(\boldsymbol{BA})\). The proof also uses the hat matrix \(\boldsymbol{H}=\boldsymbol{X}(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\) (p.30) and \(\boldsymbol{e}=(\boldsymbol{I}-\boldsymbol{H})\boldsymbol{y}\) (p.31). The matrix \(\boldsymbol{I}-\boldsymbol{H}\) is symmetric and idempotent. Idempotent means that the matrix times itself gives the same matrix.

1
\[\boldsymbol{e}=(\boldsymbol{I}-\boldsymbol{H})\boldsymbol{y}=(\boldsymbol{I}-\boldsymbol{H})(\boldsymbol{X}\boldsymbol\beta+\boldsymbol\epsilon)\]
2
\[\boldsymbol{e}=(\boldsymbol{I}-\boldsymbol{H})\boldsymbol\epsilon\]

\(\boldsymbol{H}\boldsymbol{X}=\boldsymbol{X}\), so \((\boldsymbol{I}-\boldsymbol{H})\boldsymbol{X}=\boldsymbol{0}\).

3
\[\boldsymbol{e}^T\boldsymbol{e}=\boldsymbol\epsilon^T(\boldsymbol{I}-\boldsymbol{H})^T(\boldsymbol{I}-\boldsymbol{H})\boldsymbol\epsilon=\boldsymbol\epsilon^T(\boldsymbol{I}-\boldsymbol{H})\boldsymbol\epsilon\]

Symmetric and idempotent.

4
\[\boldsymbol{e}^T\boldsymbol{e}=\mathrm{tr}\!\left(\boldsymbol\epsilon^T(\boldsymbol{I}-\boldsymbol{H})\boldsymbol\epsilon\right)=\mathrm{tr}\!\left((\boldsymbol{I}-\boldsymbol{H})\boldsymbol\epsilon\boldsymbol\epsilon^T\right)\]

The trace of a number is the number. Then use \(\mathrm{tr}(\boldsymbol{AB})=\mathrm{tr}(\boldsymbol{BA})\).

5
\[E[\boldsymbol{e}^T\boldsymbol{e}]=\mathrm{tr}\!\left((\boldsymbol{I}-\boldsymbol{H})E[\boldsymbol\epsilon\boldsymbol\epsilon^T]\right)=\mathrm{tr}\!\left((\boldsymbol{I}-\boldsymbol{H})\sigma^2\boldsymbol{I}\right)=\sigma^2\,\mathrm{tr}(\boldsymbol{I}-\boldsymbol{H})\]

\(E[\boldsymbol\epsilon\boldsymbol\epsilon^T]=\mathrm{Var}[\boldsymbol\epsilon]=\sigma^2\boldsymbol{I}\).

6
\[\mathrm{tr}(\boldsymbol{H})=\mathrm{tr}\!\left(\boldsymbol{X}(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\right)=\mathrm{tr}\!\left((\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{X}\right)=\mathrm{tr}(\boldsymbol{I}_{p+1})=p+1\]
7
\[E[\boldsymbol{e}^T\boldsymbol{e}]=\sigma^2(n-(p+1))\quad\Longrightarrow\quad E\!\left[\tfrac{1}{n-(p+1)}\boldsymbol{e}^T\boldsymbol{e}\right]=\sigma^2\]

Thus \(\hat\sigma^2\) is unbiased. The expected value of \(\hat\sigma^2_{MLE}\) is \(\frac{n-p-1}{n}\sigma^2\), which is too small. ∎

Result of this section: the course uses \(\hat\sigma^2=\boldsymbol{e}^T\boldsymbol{e}/(n-p-1)\). In the example it is 0.8. The next two sections use it to find the standard errors of \(\hat{\boldsymbol\beta}\).

05.3 Calculating \(\hat{\boldsymbol\beta}\) as a system of equations Slides p.37

This section shows the method that the slides use to calculate \(\hat{\boldsymbol\beta}\). The method solves a system of linear equations. It does not calculate the full inverse matrix.

What Slides p.37

Slides p.37 are computer code. The code does these four statistical steps:

It makes the design matrix \(\boldsymbol{X}\): a column of ones, then one column for each covariate.
It calculates \(\boldsymbol{X}^T\boldsymbol{X}\) and \(\boldsymbol{X}^T\boldsymbol{y}\).
It writes \(\hat{\boldsymbol\beta}=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{y}\) as the system \((\boldsymbol{X}^T\boldsymbol{X})\hat{\boldsymbol\beta}=\boldsymbol{X}^T\boldsymbol{y}\). Then it solves this system for \(\hat{\boldsymbol\beta}\).
The slide marks a second method as worse: calculate \((\boldsymbol{X}^T\boldsymbol{X})^{-1}\) first, then multiply it by \(\boldsymbol{X}^T\boldsymbol{y}\). The two methods give the same \(\hat{\boldsymbol\beta}\).

A system of linear equations is a set of equations in which each unknown appears only to the first power.

How Added

Calculate \(\hat{\boldsymbol\beta}\) from the system \((\boldsymbol{X}^T\boldsymbol{X})\hat{\boldsymbol\beta}=\boldsymbol{X}^T\boldsymbol{y}\)
  1. Make \(\boldsymbol{X}\) and \(\boldsymbol{y}\).
  2. Calculate \(\boldsymbol{X}^T\boldsymbol{X}\). Entry \((j,k)\) is the sum over \(i\) of (column \(j\) entry) times (column \(k\) entry).
  3. Calculate \(\boldsymbol{X}^T\boldsymbol{y}\). Entry \(j\) is the sum over \(i\) of (column \(j\) entry) times \(y_i\).
  4. Write the \(p+1\) equations of the system.
  5. Solve the equations by elimination.

Self-check: \(\boldsymbol{X}^T\boldsymbol{X}\) must be a symmetric \((p+1)\times(p+1)\) matrix. Its top-left entry must be \(n\). Put \(\hat{\boldsymbol\beta}\) back into each equation; each side must match.

05.4 Calculating \(\hat\sigma^2\) and the standard errors Slides p.38

This section calculates \(\hat\sigma^2\) and then the standard error of each \(\hat\beta_j\). Lecture 7 uses these standard errors for tests and confidence intervals.

What Slides p.38

Slides p.38 are computer code. The code does these statistical steps:

It finds \(n\) as the number of rows of \(\boldsymbol{X}\), and \(p\) as the number of columns minus 1.
It calculates the fitted values \(\hat{\boldsymbol{y}}=\boldsymbol{X}\hat{\boldsymbol\beta}\) and the residuals \(\boldsymbol{e}=\boldsymbol{y}-\hat{\boldsymbol{y}}\).
It calculates the unbiased estimate \(\hat\sigma^2=\sum e_i^2/(n-p-1)\).
It calculates \(\boldsymbol{V}=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\) and the standard errors \(\hat\sigma\sqrt{V_{jj}}\) for all coefficients.

The standard error (SE) of an estimator is an estimate of its standard deviation. To get it, put \(\hat\sigma\) in place of the unknown \(\sigma\). Slides p.27–29 give \(\hat{\boldsymbol\beta}\sim N(\boldsymbol\beta,\sigma^2(\boldsymbol{X}^T\boldsymbol{X})^{-1})\) and \(\hat\beta_j\sim N(\beta_j,\sigma^2V_{jj})\). Here \(V_{jj}\) is diagonal entry \(j\) of \(\boldsymbol{V}\), with \(j=0,1,\dots,p\).

How Added

Calculate \(\mathrm{SE}(\hat\beta_j)\)
  1. Calculate \(\hat\sigma^2=\boldsymbol{e}^T\boldsymbol{e}/(n-p-1)\) with Section 05.2.
  2. Calculate \(\boldsymbol{V}=(\boldsymbol{X}^T\boldsymbol{X})^{-1}\). Read the diagonal entry \(V_{jj}\).
  3. Multiply: \(\hat\sigma^2V_{jj}\). This is the estimate of \(\mathrm{Var}[\hat\beta_j]\).
  4. Take the square root: \(\mathrm{SE}(\hat\beta_j)=\sqrt{\hat\sigma^2V_{jj}}=\hat\sigma\sqrt{V_{jj}}\).

Self-check: Each \(V_{jj}\) must be positive. \(\boldsymbol{V}\) times \(\boldsymbol{X}^T\boldsymbol{X}\) must give the identity matrix \(\boldsymbol{I}\).

3

\(V_{00}=1.1\) belongs to \(\hat\beta_0\). \(V_{11}=0.1\) belongs to \(\hat\beta_1\). Self-check: row 1 of \(\boldsymbol{V}\) times column 1 of \(\boldsymbol{X}^T\boldsymbol{X}\) is \(1.1(5)-0.3(15)=5.5-4.5=1\).

Practice Q1 · Lecture 6 · p.40 In the case of \(p=1\) covariate, show that the matrix formula for \(\hat{\boldsymbol\beta}\) derived for multiple linear regression yields the familiar \(\hat\beta_0\) and \(\hat\beta_1\) from simple linear regression.
Answer Q1

Plan: find the inverse of the \(2\times2\) matrix \(\boldsymbol{X}^T\boldsymbol{X}\). Multiply it by \(\boldsymbol{X}^T\boldsymbol{y}\). Then write the sums with \(S_{xx}\) and \(S_{xy}\).

The answer needs two identities. First derive them.

a
\[S_{xx}=\sum(x_i-\bar x)^2=\sum x_i^2-2\bar x\sum x_i+n\bar x^2=\sum x_i^2-2n\bar x^2+n\bar x^2=\sum x_i^2-n\bar x^2\]

\(\sum x_i=n\bar x\).

b
\[S_{xy}=\sum(x_i-\bar x)(y_i-\bar y)=\sum x_iy_i-\bar y\sum x_i-\bar x\sum y_i+n\bar x\bar y=\sum x_iy_i-n\bar x\bar y\]

Now use the \(2\times2\) inverse rule: \(\left[\begin{array}{cc}a&b\\c&d\end{array}\right]^{-1}=\frac{1}{ad-bc}\left[\begin{array}{cc}d&-b\\-c&a\end{array}\right]\).

1
\[\det(\boldsymbol{X}^T\boldsymbol{X})=n\sum x_i^2-\left(\sum x_i\right)^2=n\sum x_i^2-n^2\bar x^2=n\left(\sum x_i^2-n\bar x^2\right)=nS_{xx}\]

Identity a.

2
\[(\boldsymbol{X}^T\boldsymbol{X})^{-1}=\frac{1}{nS_{xx}}\left[\begin{array}{cc}\sum x_i^2&-\sum x_i\\-\sum x_i&n\end{array}\right]\]
3
\[\hat{\boldsymbol\beta}=\frac{1}{nS_{xx}}\left[\begin{array}{cc}\sum x_i^2&-\sum x_i\\-\sum x_i&n\end{array}\right]\left[\begin{array}{c}\sum y_i\\\sum x_iy_i\end{array}\right]\]
4
\[\hat{\boldsymbol\beta}=\frac{1}{nS_{xx}}\left[\begin{array}{c}\sum x_i^2\sum y_i-\sum x_i\sum x_iy_i\\-\sum x_i\sum y_i+n\sum x_iy_i\end{array}\right]\]
5

Row 2: \(\hat\beta_1\)

\[\hat\beta_1=\frac{n\sum x_iy_i-n\bar x\cdot n\bar y}{nS_{xx}}=\frac{\sum x_iy_i-n\bar x\bar y}{S_{xx}}=\frac{S_{xy}}{S_{xx}}\]

\(\sum x_i=n\bar x\) and \(\sum y_i=n\bar y\). The last equality uses identity b.

6

Row 1: \(\hat\beta_0\)

\[\hat\beta_0=\frac{n\bar y\sum x_i^2-n\bar x\sum x_iy_i}{nS_{xx}}=\frac{\bar y\sum x_i^2-\bar x\sum x_iy_i}{S_{xx}}\]
7
\[\hat\beta_0=\frac{\bar y\left(S_{xx}+n\bar x^2\right)-\bar x\left(S_{xy}+n\bar x\bar y\right)}{S_{xx}}\]

Identities a and b in reverse: \(\sum x_i^2=S_{xx}+n\bar x^2\) and \(\sum x_iy_i=S_{xy}+n\bar x\bar y\).

8
\[\hat\beta_0=\frac{\bar yS_{xx}+n\bar x^2\bar y-\bar xS_{xy}-n\bar x^2\bar y}{S_{xx}}=\frac{\bar yS_{xx}-\bar xS_{xy}}{S_{xx}}\]
9
\[\hat\beta_0=\bar y-\frac{S_{xy}}{S_{xx}}\bar x=\bar y-\hat\beta_1\bar x\]

This is the formula of Lecture 2. ∎

Numerical check (five-point data). The sums are \(n=5\), \(\sum x_i=15\), \(\sum x_i^2=55\), \(\sum y_i=20\), \(\sum x_iy_i=66\).

Determinant: \(5(55)-15^2=275-225=50\). Also \(nS_{xx}=5(10)=50\). The two values agree.
Matrix formula, row 2: \(\hat\beta_1=\frac{5(66)-15(20)}{50}=\frac{330-300}{50}=\frac{30}{50}=0.6\).
Matrix formula, row 1: \(\hat\beta_0=\frac{55(20)-15(66)}{50}=\frac{1100-990}{50}=\frac{110}{50}=2.2\).
SLR formulas: \(\hat\beta_1=6/10=0.6\) and \(\hat\beta_0=4-0.6(3)=4-1.8=2.2\).
Section 5.3 got the same \(\hat{\boldsymbol\beta}=(2.2,\,0.6)^T\) by elimination. All three methods agree. ▲

Practice Q2 · Lecture 6 · p.41 In the case of \(p=1\) covariate, find the covariance between \(\hat\beta_0\) and \(\hat\beta_1\) using the above variance covariance matrix for \(\hat{\boldsymbol\beta}\).
Answer Q2

The covariance \(\mathrm{cov}(U,W)=E[(U-E[U])(W-E[W])]\) shows how much two random variables change together. The "above variance covariance matrix" is the covariance matrix \(\mathrm{Var}[\hat{\boldsymbol\beta}]=\sigma^2(\boldsymbol{X}^T\boldsymbol{X})^{-1}\) from p.27. Its off-diagonal entry is \(\mathrm{cov}(\hat\beta_0,\hat\beta_1)\).

1
\[\mathrm{Var}[\hat{\boldsymbol\beta}]=\left[\begin{array}{cc}\mathrm{Var}(\hat\beta_0)&\mathrm{cov}(\hat\beta_0,\hat\beta_1)\\\mathrm{cov}(\hat\beta_1,\hat\beta_0)&\mathrm{Var}(\hat\beta_1)\end{array}\right]=\sigma^2(\boldsymbol{X}^T\boldsymbol{X})^{-1}\]
2
\[\sigma^2(\boldsymbol{X}^T\boldsymbol{X})^{-1}=\frac{\sigma^2}{nS_{xx}}\left[\begin{array}{cc}\sum x_i^2&-\sum x_i\\-\sum x_i&n\end{array}\right]\]

Put in the inverse from step 2 of Q1.

3
\[\mathrm{cov}(\hat\beta_0,\hat\beta_1)=\frac{\sigma^2}{nS_{xx}}\left(-\sum x_i\right)\]

Row 1, column 2.

4
\[\mathrm{cov}(\hat\beta_0,\hat\beta_1)=\frac{\sigma^2}{nS_{xx}}\left(-n\bar x\right)\]
5
\[\mathrm{cov}(\hat\beta_0,\hat\beta_1)=-\frac{\sigma^2\bar x}{S_{xx}}\]

When \(\bar x>0\), the covariance is negative. The fitted line always goes through \((\bar x,\bar y)\), so a larger \(\hat\beta_1\) gives a smaller \(\hat\beta_0=\bar y-\hat\beta_1\bar x\). Figure 5-1 shows this point. ∎

Numerical check (five-point data). Use \(\hat\sigma^2=0.8\) in place of \(\sigma^2\).

Formula: \(-\frac{0.8(3)}{10}=-\frac{2.4}{10}=-0.24\).
Matrix entry: Section 05.4 gave \(V_{01}=-0.3\), so \(\hat\sigma^2V_{01}=0.8(-0.3)=-0.24\). The two values agree. ▲

Q3 Added

A data set has \(n=4\) observations: \(x=(0,1,2,3)\) and \(y=(1,3,2,6)\). The fitted line is \(\hat y=0.9+1.4x\). (a) Calculate \(\boldsymbol{e}^T\boldsymbol{e}\), \(\hat\sigma^2_{MLE}\), and the unbiased \(\hat\sigma^2\). (b) Calculate \(S_{xx}\) and \(\mathrm{SE}(\hat\beta_1)=\sqrt{\hat\sigma^2V_{11}}\). (c) Calculate \(\mathrm{cov}(\hat\beta_0,\hat\beta_1)\) with \(\hat\sigma^2\) in place of \(\sigma^2\).

Answer Q3
1

(a) Fitted values 05.1 How step 1

\[\hat y_1=0.9,\quad \hat y_2=0.9+1.4=2.3,\quad \hat y_3=0.9+2.8=3.7,\quad \hat y_4=0.9+4.2=5.1\]
2

(a) Residuals 05.1 How step 2

\[e_1=1-0.9=0.1,\quad e_2=3-2.3=0.7,\quad e_3=2-3.7=-1.7,\quad e_4=6-5.1=0.9\]

Self-check: \(\sum e_i=0.1+0.7-1.7+0.9=0\) and \(\sum x_ie_i=0+0.7-3.4+2.7=0\).

3

(a) Residual sum of squares 05.1 How step 3

\[\boldsymbol{e}^T\boldsymbol{e}=0.01+0.49+2.89+0.81=4.2\]
4

(a) MLE 05.1 How step 4

\[\hat\sigma^2_{MLE}=\frac{4.2}{4}=1.05\]
5

(a) Unbiased estimate 05.2 How

\[n-p-1=4-1-1=2,\qquad \hat\sigma^2=\frac{4.2}{2}=2.1\]

Self-check: \(2.1/1.05=2=4/2=n/(n-p-1)\).

6

(b) \(S_{xx}\) and \(V_{11}\) Q1 step 2

\[\bar x=\frac{6}{4}=1.5,\qquad S_{xx}=2.25+0.25+0.25+2.25=5\]
\[V_{11}=\frac{n}{nS_{xx}}=\frac{1}{S_{xx}}=\frac15=0.2\]

The bottom-right entry of the inverse in Q1 is \(n/(nS_{xx})\).

7

(b) SE 05.4 How steps 3–4

\[\hat\sigma^2V_{11}=2.1(0.2)=0.42,\qquad \mathrm{SE}(\hat\beta_1)=\sqrt{0.42}=0.6481\]

This is the SLR form \(\mathrm{SE}(\hat\beta_1)=\hat\sigma/\sqrt{S_{xx}}=\sqrt{2.1}/\sqrt{5}=1.4491/2.2361=0.6481\).

8

(c) Covariance Q2 step 5

\[\mathrm{cov}(\hat\beta_0,\hat\beta_1)=-\frac{\hat\sigma^2\bar x}{S_{xx}}=-\frac{2.1(1.5)}{5}=-\frac{3.15}{5}=-0.63\]

The value is negative because \(\bar x=1.5>0\). ▲

Result of this unit: the MLE of \(\sigma^2\) is \(\boldsymbol{e}^T\boldsymbol{e}/n\), and the course uses the unbiased \(\boldsymbol{e}^T\boldsymbol{e}/(n-p-1)\). Multiply it by a diagonal entry of \((\boldsymbol{X}^T\boldsymbol{X})^{-1}\) and take the square root to get the SE of each \(\hat\beta_j\). When \(p=1\), these matrix formulas give the SLR formulas. Lecture 7 uses the SEs for tests and confidence intervals.
